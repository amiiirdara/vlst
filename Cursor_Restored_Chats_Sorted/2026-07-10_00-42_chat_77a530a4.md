## Script

[`../code/modeling/tools/loco_shap_objectives.py`](code/modeling/loco_shap_objectives.py)

### Run (GPU + TabPFN)

```bash
# Full run: LOCO×3 + SHAP×3 + subset evaluation + report
python code/modeling/loco_shap_objectives.py --topk 20

# Faster smoke test (cap LOCO ablations)
python code/modeling/loco_shap_objectives.py --topk 12 --loco-max-features 20

```

Outputs go to `data/result/loco_shap/`:

- `loco_{pr_auc,f1,f2}.csv` — drop-one importance per objective
- `shap_{pr_auc,f1,f2}.csv` — coalition-metric Shapley ranking
- `subset_evaluation.csv` — refit TabPFN on each top-K list
- `overlap_matrix.csv`, `loco_by_objective.png`, `overlap_heatmap.png`
- **`report.md`** — full narrative report

### Design (aligned with `tabpfn.ipynb` §10)

| Method              | Per objective                               | Scoring                                                                               |
|---------------------|---------------------------------------------|---------------------------------------------------------------------------------------|
| **LOCO**            | Refit TabPFN without each column            | `importance = baseline − score_without` on **test**                                   |
| **SHAP**            | Coalition Shapley on LOCO universe (2×TOPK) | Global **pr_auc / f1 / f2** on explained test rows (mask to background, **no refit**) |
| **FFS** (reference) | Greedy forward add on holdout               | Same three metrics                                                                    |

For **f1** and **f2**, the threshold is tuned on the same scores used for that evaluation (same logic as FFS holdout in
`tabpfn.ipynb`).

Core scoring helper:

```python
def metric_score(y_true, probas, metric):
    if metric == "pr_auc":
        return average_precision_score(y_true, probas)
    if metric == "f1":
        t, _ = select_threshold(y_true, probas, strategy="f1")
        return f1_score(y_true, (probas >= t).astype(int), zero_division=0)
    if metric == "f2":
        t, _ = select_threshold(y_true, probas, strategy="f2", beta=2.0)
        return fbeta_score(y_true, (probas >= t).astype(int), beta=2.0, zero_division=0)
```
