# VLST manuscript figure captions

Publication figure panels for the VLST (very late stent thrombosis) prediction study.  
All panels use the **Harmony** qualitative palette, **DejaVu Sans** at 9–11 pt, and letter labels (**A**, **B**, …).  
Generated by `code/figures/make_figure_panels.py` → `data/figures/`.

---

## Figure 1 · Preprocessing & quality control

**Short title:** Cohort construction, class imbalance, and leak-aware QC.

### Panel A — Preprocessing flow
Schematic of the modeling cohort pipeline. Raw VLST data (5,185 patients) were stripped of identifiers (`NO.`, `Name`) and the leakage column *Time since stent implantation*, which is strongly coupled to the outcome and not a legitimate pre-event predictor. No exact duplicate rows were removed. After feature engineering (81 modeling columns for TabPFN/raw views; 88 after scaling and one-hot encoding for tree models), data were split **70% train / 30% test** with stratification on `Stent thrombosis` (`random_state = 42`).

### Panel B — Target class distribution
Bar chart of VLST vs non-VLST counts in the full cleaned cohort (5,093 negatives, 92 positives; **1.77%** event rate). The extreme imbalance motivates PR-AUC as the primary ranking metric and F₂-based threshold tuning.

### Panel C — Stratified hold-out
Comparison of train and test set sizes and positive counts. Train: 3,629 patients (64 positives, **1.76%**); test: 1,556 patients (28 positives, **1.80%**). Stratification preserves the rare-event rate across splits.

### Panel D — Quality control summary
Tabulated QC checks: zero missing feature values after cleaning, zero duplicate rows, explicit leakage removal, and feature-type counts (57 binary, 24 continuous, 1 categorical stent-brand column before encoding). Preprocessed matrices expand to 88 dimensions after median/mode imputation, standardization, and one-hot encoding (fit on train only).

**Figure 1 caption (full):**  
*Preprocessing and quality control for the VLST cohort. **(A)** Leak-aware cleaning and stratified 70/30 split. **(B)** Overall class imbalance (1.77% VLST). **(C)** Train and test sizes with preserved positive rate. **(D)** QC summary including feature types and leakage handling. TSSI = time since stent implantation (dropped).*

## Figure 2 · Compare models

**Short title:** Unified leaderboard — baselines, tree ensembles, and TabPFN blends.

### Panel A — Test PR-AUC ranking
Horizontal bar chart of **average precision (PR-AUC)** on the 30% hold-out test set (28 positives). Colors indicate model family: blue = classical baselines (LR, RF, CatBoost, XGB, LGB), orange = advanced SLSQP/calibrated blends, green = TabPFN standalone and blends. TabPFN meta-LR stacking (`tabpfn_blend_stacking`, PR-AUC ≈ 0.816) ranks highest among saved runs; unified pipeline TabPFN standalone ≈ 0.765. Tree boosters cluster near 0.65–0.71 PR-AUC.

### Panel B — Cross-validated PR-AUC (classical models)
Five-fold stratified CV on the training portion (TabPFN excluded — OOF protocol not comparable). Error bars = ±1 SD across folds. Provides optimistic-bias context for tree/boosters before hold-out evaluation.

### Panel C — Precision–recall curves (test)
PR curves for fitted gradient-boosted models on the preprocessed (scaled + OHE) feature matrix. TabPFN blend AP is annotated in the legend from the saved leaderboard (not overlaid — TabPFN scores require GPU inference). Baseline prevalence ≈ 1.8% (horizontal reference implicit in curve shape).

### Panel D — ROC curves (test)
ROC curves for the same models. High ROC-AUC (>0.94) reflects the severe class skew; **PR-AUC is the preferred metric** for model selection.

**Figure 2 caption (full):**  
*Model comparison on the stratified 70/30 split (n_test = 1,556, 28 VLST events). **(A)** Hold-out PR-AUC ranking across baselines, advanced blends, and TabPFN variants (Harmony family colors). **(B)** Five-fold CV PR-AUC for classical models (mean ± SD). **(C–D)** Test-set precision–recall and ROC curves for tree boosters on the scaled feature view; top TabPFN blend metrics shown from saved evaluation.*

## Figure 3 · Top model results

**Short title:** Operational performance of the best TabPFN stacking blend.

### Panel A — Discrimination metrics (TabPFN stacking blend)
Bar chart of PR-AUC, ROC-AUC, precision, recall, and F1 for **`tabpfn_blend_stacking`** (meta logistic regression on OOF base-learner probabilities). Reported values from `tabpfn.ipynb` hold-out evaluation: PR-AUC ≈ 0.816, F1 ≈ 0.75 at OOF F₂-tuned threshold.

### Panel B — Confusion matrix (tree proxy)
Confusion matrix at the F₂-optimal threshold for an XGBoost proxy trained on the scaled pipeline (local reproducibility when TabPFN probability vectors are not materialized). Shown for qualitative error structure: false positives vs missed VLST events on n_test = 1,556.

### Panel C — PR curve with operating point
Precision–recall curve for the tree proxy with the F₂-tuned threshold marked (red point). Illustrates the precision–recall trade-off in the high-threshold regime typical for TabPFN (>0.79–0.88).

### Panel D — Operational metrics comparison
Grouped bars comparing precision, recall, and F1 for the TabPFN stacking blend (saved metrics) vs the tree proxy at tuned thresholds. Highlights that blend ensembles improve ranking (PR-AUC) while threshold policy drives operational precision/recall.

**Figure 3 caption (full):**  
*Hold-out results for the top-performing TabPFN meta-LR stacking blend. **(A)** Summary discrimination and operational metrics (saved evaluation). **(B)** Confusion matrix for an XGBoost proxy at F₂-optimal threshold (n_test = 1,556). **(C)** PR curve with operating point. **(D)** Precision, recall, and F1 — TabPFN blend vs tree proxy. Thresholds tuned on OOF/calibration scores, not the test set.*

## Figure 4 · Top features

**Short title:** Feature importance — model-based (LOCO) and univariate (EDA).

### Panel A — TabPFN LOCO importance (top 12)
Leave-one-covariate-out (LOCO) importance: drop in hold-out PR-AUC when each feature is removed from the TabPFN input matrix (81 raw features). Top contributors include **eGFR**, **Cre** (creatinine), **visual thrombus**, **P-LM** (left-main involvement), **moderate/severe tortuosity**, and **moderate/severe calcification** — consistent with renal function, angiographic complexity, and thrombotic burden as VLST risk signals.

### Panel B — Univariate correlation with VLST
Absolute Pearson correlation with the binary outcome (leakage column excluded). **LV** (likely lesion/vessel score), **WBC**, and **eGFR** rank highest among non-leakage features; magnitudes are modest (|r| < 0.16), supporting multivariate/nonlinear modeling.

### Panel C — Significant continuous features (Mann–Whitney)
−log₁₀(p-value) from Mann–Whitney U tests (VLST vs non-VLST) for continuous variables. Dashed line: p = 0.05. Green bars = significant at α = 0.05 after univariate testing; grey = non-significant. Complements Panel A by showing which lab/vessel variables differ in marginal distribution.

**Figure 4 caption (full):**  
*Top predictors of very late stent thrombosis. **(A)** TabPFN LOCO importance (Δ PR-AUC upon removal; top 12 of 81 features). **(B)** Univariate |correlation| with VLST (Time since stent implantation excluded as leakage). **(C)** Mann–Whitney significance for continuous features (−log₁₀ p; dashed line p = 0.05). LOCO captures multivariate contribution; EDA panels capture marginal association.*
