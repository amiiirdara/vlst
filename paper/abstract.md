# Abstract

**Background.** Very late stent thrombosis (VLST) is Academic Research Consortium 2007 definite stent thrombosis more than one year after PCI. Wang 2020 published a Cox integer score on this derivation cohort (published derivation c-statistic 0.80 [0.75, 0.85]). This analysis uses the same derivation file; it does not replace Wang’s Shantou test of Wang’s score.

**Objective.** On the Wang 2020 derivation cohort: catalogue associations; rank nested-CV TabPFN checkpoints after anti-leakage drops (v3 vs v3.5; thinking vs local), with class-weighted library-default trees and logistic regression as an **untuned reference panel** (not a hyperparameter-matched classic-vs-TabPFN contest); demonstrate leakage on 70/30 GridSearch twins; and attribute TabPFN predictions in two interpretability notebooks. The published Wang integer points are scored as a frozen historical comparator.

**Methods.** Analysed file n = 5185 patients, 92 VLST events, prevalence 0.0177. Outcome = binary `Stent thrombosis`. Nested anti-leakage is ON (ALL LEAKS OFF): drop identifiers, TSSI (mixed time-to-event vs completed follow-up), and WBC (recording-precision / batch marker); quantize `Cre`/`CaI`/`Fiberinogen`/`Fast-Glu` **before** split; stent codebook on each **train fold only**; no SMOTE; scaler/OHE cloned inside splits. Nested evaluation is stratified 5 outer × 4 inner CV (seed 42); the inner loop tunes the F1 threshold only. Classics are an untuned reference panel (library defaults plus class weighting); GridSearchCV winners from the 70/30 leakage twins (five flags inverted together) are not imported. Nested TabPFN pins: `tabpfn==9.0.0` / `tabpfn-client==0.6.0`; thinking-high uses `tabpfn_client` (effort high, metric average_precision); local arms are not thinking. Primary ranking metric is PR-AUC at prevalence 0.0177. Uncertainty on pooled out-of-fold scores uses a stratified patient-level bootstrap (`n_boot=2000`, seed 42). Multivariable association is the identified Table 4b unweighted Bernoulli logit (not prediction). Attribution uses `tabpfn_interpretability_fs_pdp.ipynb` and `tabpfn_interpretability_shap.ipynb` under the same OFF cleaning.

**Results.** Among nine nested-CV arms (anti-leakage ON), TabPFN thinking v3.5 had PR-AUC 0.9212 [0.8785, 0.9613], ROC-AUC 0.9963, Brier 0.0047; nested recall 0.8370, F1 0.8603. TabPFN v3.5 (local) had PR-AUC 0.8957 [0.8446, 0.9426], Brier 0.0048. Highest library-default classic PR-AUC was XGBoost 0.6322, then LightGBM 0.6271. Paired bootstrap Δ PR-AUC thinking v3.5 − LightGBM was 0.2941 (0.2071–0.3805), P(Δ ≤ 0) = 0/2000. The frozen Wang integer score had ROC-AUC 0.8013 and PR-AUC 0.1032 on the same 5185 rows (weights not re-fit). Table 4b adjusted ORs (Wald 95% CI): `1.1:1Post dilation` 0.152 [0.081, 0.286]; Clopidogrel 0.480 [0.293, 0.787]; WBC 1.972 [1.667, 2.331] — associated with recorded VLST, not treatment effects.

**Conclusions.** On this derivation cohort, thinking v3.5 had the highest nested-CV PR-AUC among the nine fitted arms (0.9212); TabPFN v3.5 (0.8957) also exceeded library-default XGBoost (0.6322) and LightGBM (0.6271). That ranking is not a hyperparameter-matched contest against tuned boosting. TSSI, WBC, raw lab decimals, a full-cohort stent codebook, and train SMOTE must not enter nested-CV binary classifiers as if they were baseline covariates. Association findings are not treatment effects. Nested-CV discrimination on the derivation file is not external validation; the ML models were not externally or temporally tested.
