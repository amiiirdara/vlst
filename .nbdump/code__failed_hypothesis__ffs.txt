# Forward Feature Selection (FFS) for VLST

This notebook performs **forward feature selection** using the **preprocessed** VLST data from `../modeling/preprocessing/preprocessing.ipynb`. It uses cross-validated scoring to greedily add features that improve model performance (e.g. F1 or PR-AUC).

- **Data**: `data/processed/` (X_train, y_train, feature_names; resolved from repo root)
- **Method**: Sequential forward selection with stratified CV
- **Output**: Selected feature names and indices saved to `data/result/ffs/`

########## CELL 1 [markdown] ##########
## 1. Imports and paths

########## CELL 2 [code] ##########
import os
from pathlib import Path

import numpy as np
import pandas as pd
from sklearn.feature_selection import SequentialFeatureSelector
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold

np.random.seed(42)

def _find_repo_root() -> Path:
    here = Path.cwd().resolve()
    for p in [here, *here.parents]:
        if (p / "data" / "raw" / "VLST.csv").is_file():
            return p
    raise FileNotFoundError("Could not locate data/raw/VLST.csv above cwd.")
REPO_ROOT = _find_repo_root()

PROCESSED_DIR = str(REPO_ROOT / "data" / "processed")
RESULT_DIR = str(REPO_ROOT / "data" / "result" / "ffs")
os.makedirs(RESULT_DIR, exist_ok=True)

## 3. Forward feature selection

########## CELL 6 [markdown] ##########
We use `SequentialFeatureSelector` with a classifier and stratified CV. You can set `n_features_to_select` (integer or fraction) and `scoring` (e.g. `'f1'`, `'average_precision'`).

########## CELL 7 [code] ##########
N_FEATURES_TO_SELECT = 30  # top 30 features
SCORING = "f1"  # or 'average_precision', 'roc_auc'
CV_SPLITS = 5

cv = StratifiedKFold(n_splits=CV_SPLITS, shuffle=True, random_state=42)
estimator = LogisticRegression(class_weight="balanced", max_iter=2000, random_state=42)

sfs = SequentialFeatureSelector(
    estimator=estimator,
    n_features_to_select=min(N_FEATURES_TO_SELECT, X_train.shape[1]),
    direction="forward",
    scoring=SCORING,
    cv=cv,
    n_jobs=-1,
)
sfs.fit(X_train, y_train)

## 6. (Optional) Step-by-step selection history

If you need the score at each step, run a simple custom forward loop below. Otherwise the sklearn `SequentialFeatureSelector` above is sufficient.

########## CELL 14 [code] ##########
def forward_selection_custom(
        X, y, feature_names, estimator, cv, scoring="f1", max_features=30
):
    """Simple forward selection: at each step add the feature that gives best CV score."""
    n_features = X.shape[1]
    selected = []
    remaining = list(range(n_features))
    history = []

    for step in range(min(max_features, len(remaining))):
        best_score = -np.inf
        best_idx = None
        for idx in remaining:
            cols = selected + [idx]
            X_sub = X[:, cols]
            scores = cross_val_score(estimator, X_sub, y, cv=cv, scoring=scoring)
            mean_score = scores.mean()
            if mean_score > best_score:
                best_score = mean_score
                best_idx = idx
        if best_idx is None:
            break
        selected.append(best_idx)
        remaining.remove(best_idx)
        history.append(
            {"step": step + 1, "feature": feature_names[best_idx], "score": best_score}
        )

    return selected, history
