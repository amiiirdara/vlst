# VLST — TabPFN (Tabular Foundation Model)

**TabPFN** ([Prior Labs](https://github.com/PriorLabs/TabPFN)) is a **Prior-Data Fitted Network (PFN)** that performs
**In-Context Learning (ICL)**. Unlike XGBoost / LightGBM, it does **not** update weights during `.fit()`:

- `.fit(X_train, y_train)` simply **stores the training data as context**.
- `.predict()` / `.predict_proba()` run a **single forward pass** through a Transformer to approximate
  **Bayesian inference** over the stored context.

### Implementation guidelines followed here

- **No manual preprocessing.** We do **not** scale, one-hot encode, or remove outliers. TabPFN handles
  heterogeneous columns and **missing values** natively. (Raw mode keeps `NaN`s; categorical text columns
  get minimal integer codes — never one-hot.)
- **Hardware.** Uses a **GPU** automatically when available; falls back to CPU. On **Kaggle**, enable
  **GPU T4** and see **§0** for dataset paths, `TABPFN_TOKEN` secrets, and `is_kaggle_env` handling.
  Set `USE_TABPFN_CLIENT=True` in §3 to use the Prior Labs **cloud API** instead of local inference.
- **Batch prediction.** The whole test set is passed to `predict_proba` in **one** call — predicting
  row-by-row is wasteful because it recomputes the context every time.
- **Data regimes (TabPFN-3, for reference):** 1,000,000×200 / 100,000×2,000 / 1,000×20,000.
  VLST (~5k rows × ~80–170 cols) sits comfortably inside the **v2.5** regime, so v2.5 is used.

### Interpretability (training-free → cheap)

Because "retraining" is just another fast forward pass, two analyses become tractable:

- **LOCO (Leave-One-Covariate-Out):** drop one feature, re-store the context, forward pass, and measure the
  drop in **pr_auc / f1 / f2** on the test set (threshold re-tuned for f1/f2) — the *unique* information each feature carries per objective.
- **Exact SHAP (masked forward passes):** (§8a) local Shapley values on \(P(\text{positive})\); (§8b) coalition-metric
  Shapley on **pr_auc / f1 / f2** via background masking — no retraining.

### Dataset

`data/raw/VLST.csv` — target **`Stent thrombosis`** (rare positive ~1–2%). The leakage feature
**`Time since stent implantation`** is dropped (consistent with the other modeling notebooks).

def load_raw():
    """Minimal, TabPFN-native handling: keep NaNs, code text columns, no scaling/one-hot."""
    df = pd.read_csv(RAW_PATH)
    df = df.drop(columns=[c for c in ID_COLS if c in df.columns])
    y = df[TARGET_COL].astype(int).to_numpy()
    drop = [TARGET_COL] + [c for c in DROP_FEATURES if c in df.columns]
    X_df = df.drop(columns=drop)
    for c in X_df.columns:
        if X_df[c].dtype == object:
            coerced = pd.to_numeric(X_df[c].astype(str).str.strip(), errors="coerce")
            if coerced.notna().mean() >= 0.5:        # genuinely numeric (e.g. "21.00 ")
                X_df[c] = coerced
            else:                                     # categorical text -> integer codes (NOT one-hot)
                codes = X_df[c].astype("category").cat.codes.astype(float)
                X_df[c] = codes.where(codes >= 0, np.nan)
    return X_df.to_numpy(dtype=float), y, list(X_df.columns)

## 5. Fit TabPFN context and batch-predict

`fit` only **stores the context**; `predict_proba` does a **single batched forward pass** over the entire
test set. Under strong imbalance we (optionally) tune the positive-class threshold by max-F1 on a stratified
slice of the training set, then refit the context on **all** training rows.

def pos_proba(clf, X):
    """Positive-class probability, robust to class ordering."""
    classes = list(clf.classes_)
    idx = classes.index(1) if 1 in classes else 1
    return np.asarray(clf.predict_proba(X)[:, idx], dtype=float)


def oof_pos_proba(make_clf, X, y, n_splits=5, seed=RANDOM_STATE):
    """Out-of-fold positive-class probabilities over ALL of X.

    Far more stable than a single small val slice: every training positive contributes
    exactly one held-out score, so the threshold is tuned on all 74 positives, not ~11.
    """
    oof = np.zeros(len(y), dtype=float)
    skf = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=seed)
    for k, (tr, va) in enumerate(skf.split(X, y), 1):
        m = make_clf(); m.fit(X[tr], y[tr])
        oof[va] = pos_proba(m, X[va])
        print(f"  OOF fold {k}/{n_splits}")
    return oof


def select_threshold(y_true, scores, *, strategy="f2", beta=2.0,
                     min_precision=0.30, target_recall=0.80, grid_points=199):
    """Pick a decision threshold from validation scores under a chosen objective."""
    grid = np.linspace(0.01, 0.99, grid_points)
    P, R, F1, FB = [], [], [], []
    for t in grid:
        pred = (scores >= t).astype(int)
        P.append(precision_score(y_true, pred, zero_division=0))
        R.append(recall_score(y_true, pred, zero_division=0))
        F1.append(f1_score(y_true, pred, zero_division=0))
        FB.append(fbeta_score(y_true, pred, beta=beta, zero_division=0))
    P, R, F1, FB = map(np.asarray, (P, R, F1, FB))

    if strategy == "f1":
        i = int(np.argmax(F1))
    elif strategy in ("f2", "fbeta"):
        i = int(np.argmax(FB))
    elif strategy == "recall_at_precision":
        ok = np.where(P >= min_precision)[0]
        i = int(ok[np.argmax(R[ok])]) if len(ok) else int(np.argmax(F1))
    elif strategy == "target_recall":
        ok = np.where(R >= target_recall)[0]
        i = int(ok[np.argmax(P[ok])]) if len(ok) else int(np.argmax(R))
    else:
        raise ValueError(f"Unknown THRESHOLD_STRATEGY: {strategy}")

    info = {"precision": float(P[i]), "recall": float(R[i]),
            "f1": float(F1[i]), f"f{beta:g}": float(FB[i])}
    return float(grid[i]), info


def tradeoff_threshold_grid(*, start=1.0, stop=0.4, step=0.05, fine_until=0.9, fine_step=0.01):
    """1.00→fine_until in fine_step, then (fine_until−step)→stop in step."""
    fine = np.arange(start, fine_until - fine_step / 2, -fine_step)
    coarse = np.arange(fine_until - step, stop - step / 2, -step)
    return np.concatenate([fine, coarse]) if len(coarse) else fine


def fp_fn_tradeoff_table(y_true, scores, *, start=1.0, stop=0.4, step=0.05,
                         fine_until=0.9, fine_step=0.01):
    """Operating points on a fixed threshold grid (high → low = min FP → min FN)."""
    y_true = np.asarray(y_true)
    scores = np.asarray(scores, dtype=float)
    thresholds = tradeoff_threshold_grid(
        start=start, stop=stop, step=step, fine_until=fine_until, fine_step=fine_step,
    )

    rows = []
    for t in thresholds:
        pred = (scores >= t).astype(int)
        tn, fp, fn, tp = confusion_matrix(y_true, pred, labels=[0, 1]).ravel()
        rows.append({
            "threshold": float(t),
            "precision": precision_score(y_true, pred, zero_division=0),
            "recall": recall_score(y_true, pred, zero_division=0),
            "f1": f1_score(y_true, pred, zero_division=0),
            "TN": int(tn), "FP": int(fp), "FN": int(fn), "TP": int(tp),
        })
    out = pd.DataFrame(rows).reset_index(drop=True)
    out.insert(0, "point", np.arange(1, len(out) + 1))
    if len(out) == 1:
        out.insert(1, "priority", ["tradeoff"])
    else:
        labels = ["min_FP"] + ["tradeoff"] * (len(out) - 2) + ["min_FN"]
        out.insert(1, "priority", labels)
    return out

## 6a. FP / FN trade-off (operating-point sweep)

Your confusion matrix at the chosen threshold is one **operating point** on the precision–recall curve.
Lower the threshold → more positives flagged → **fewer false negatives, more false positives**.
Raise it → the opposite.

The table sweeps **fixed thresholds** from `TRADEOFF_THRESH_START` down to `TRADEOFF_THRESH_STOP`
on the **test scores** (`y_prob`): **0.01 steps** from 1.00 down to `TRADEOFF_THRESH_FINE_UNTIL`
(0.90), then **0.05 steps** from 0.85 down to 0.40. This gives fine resolution where TabPFN
operates (~0.88–0.95) while keeping the lower range coarse.
For deployment, mirror the same grid on OOF train scores (§6b) before picking a cut-off.

## 6b. Threshold tuning & recall analysis

The decision threshold is the **single biggest lever for recall** on this rare-positive problem
(~1.7% positives). The model ranks well; the question is *where* you
cut the probability.

Two improvements over the original single-slice tuning:

1. **Out-of-fold (OOF) tuning** — the threshold is now chosen on cross-validated scores over **all**
   training positives instead of ~11 in a 15% slice, so it is far less noisy.
2. **Objective you can pick** via `THRESHOLD_STRATEGY` in §3:
   - `f1` — balanced precision/recall
   - `f2` *(default)* — recall-leaning (recall weighted ~2× precision)
   - `recall_at_precision` — maximise recall subject to precision ≥ `MIN_PRECISION`
   - `target_recall` — the highest-precision threshold that still reaches `TARGET_RECALL`

The sweep below is computed on **OOF training scores** (no test peeking for selection). The strategy
table then reports what each chosen threshold yields on the **frozen test set** — for transparency only,
not for picking the operating point.

## 6c. Bootstrap confidence intervals (how trustworthy are these numbers

We quantify that with a **stratified bootstrap**: resample the positives and negatives *separately* (with
replacement) `N_BOOTSTRAP` times so the test prevalence stays fixed and both classes are always present
(needed for ROC-AUC / PR-AUC). For each resample we recompute the metrics at the **chosen `THRESHOLD`** and
report the point estimate plus the central `BOOTSTRAP_CI`% percentile interval.

Wide intervals here are expected and honest — they tell you whether a recall improvement is real or noise.

########## CELL 19 [code] ##########
def bootstrap_ci(y_true, scores, threshold, *, n_boot=2000, ci=95, beta=2.0, seed=RANDOM_STATE):
    """Stratified bootstrap CIs for threshold metrics + ranking AUCs on the test set."""
    rng = np.random.default_rng(seed)
    pos_idx = np.flatnonzero(y_true == 1)
    neg_idx = np.flatnonzero(y_true == 0)
    lo_q, hi_q = (100 - ci) / 2, 100 - (100 - ci) / 2

    fbeta_key = f"f{beta:g}"
    draws = {"precision": [], "recall": [], "f1": [], fbeta_key: [], "roc_auc": [], "pr_auc": []}
    for _ in range(n_boot):
        idx = np.concatenate([
            rng.choice(pos_idx, size=len(pos_idx), replace=True),
            rng.choice(neg_idx, size=len(neg_idx), replace=True),
        ])
        yt, sc = y_true[idx], scores[idx]
        pred = (sc >= threshold).astype(int)
        draws["precision"].append(precision_score(yt, pred, zero_division=0))
        draws["recall"].append(recall_score(yt, pred, zero_division=0))
        draws["f1"].append(f1_score(yt, pred, zero_division=0))
        draws[fbeta_key].append(fbeta_score(yt, pred, beta=beta, zero_division=0))
        draws["roc_auc"].append(roc_auc_score(yt, sc))
        draws["pr_auc"].append(average_precision_score(yt, sc))

    pred_full = (scores >= threshold).astype(int)
    point = {
        "precision": precision_score(y_true, pred_full, zero_division=0),
        "recall": recall_score(y_true, pred_full, zero_division=0),
        "f1": f1_score(y_true, pred_full, zero_division=0),
        fbeta_key: fbeta_score(y_true, pred_full, beta=beta, zero_division=0),
        "roc_auc": roc_auc_score(y_true, scores),
        "pr_auc": average_precision_score(y_true, scores),
    }
    rows = []
    for k, vals in draws.items():
        vals = np.asarray(vals)
        rows.append({
            "metric": k,
            "point": round(float(point[k]), 4),
            "ci_low": round(float(np.percentile(vals, lo_q)), 4),
            "ci_high": round(float(np.percentile(vals, hi_q)), 4),
            "std": round(float(vals.std()), 4),
        })
    return pd.DataFrame(rows)

## 7. LOCO (Leave-One-Covariate-Out) feature importance

For each feature we **remove its column**, re-store the TabPFN context, run one forward pass, and record how
much the test metric **drops** versus the full-feature baseline. We repeat under three objectives —
`pr_auc`, `f1`, and `f2` — matching the FFS holdout scorers in §10. For `f1`/`f2` the threshold is tuned on
the test scores at each ablation (same logic as FFS holdout). A larger drop ⇒ the feature carries more *unique*
predictive information for that objective.


########## CELL 21 [code] ##########
def metric_score(y_true, probas, metric):
    """Score probas under pr_auc / f1 / f2 (threshold tuned on y_true for f1/f2)."""
    if metric == "pr_auc":
        return float(average_precision_score(y_true, probas))
    if metric == "roc_auc":
        return float(roc_auc_score(y_true, probas))
    if metric == "f1":
        t, _ = select_threshold(y_true, probas, strategy="f1", beta=1.0)
        pred = (probas >= t).astype(int)
        return float(f1_score(y_true, pred, zero_division=0))
    if metric == "f2":
        t, _ = select_threshold(y_true, probas, strategy="f2", beta=2.0)
        pred = (probas >= t).astype(int)
        return float(fbeta_score(y_true, pred, beta=2.0, zero_division=0))
    raise ValueError(f"Unknown metric: {metric}")


def loco_importance(make_clf, X_tr, y_tr, X_te, y_te, names, *, metric="pr_auc", max_features=None):

### 7.1 How to read the LOCO figures

**What LOCO measures.** For each objective (`pr_auc`, `f1`, `f2`) and each feature \(j\), we drop column \(j\),
refit TabPFN on the remaining \(d-1\) columns, and score the test set. The bar height is
`baseline_score − score_without_j`. For `f1`/`f2` the threshold is re-tuned on test probas at every ablation
(same policy as FFS holdout in §10).

**Three panels — one per objective**
- **`pr_auc`:** drop in ranking quality (threshold-free).
- **`f1`:** drop in best achievable F1 on the test scores.
- **`f2`:** drop in recall-leaning F\(_2\) (β=2).

**How to read a bar.** A **large positive bar** means removing that feature hurts the objective a lot.
Near **zero** ⇒ redundant given other columns. **Negative** (orange) ⇒ metric improved when removed.

**Interpretation for VLST.** Renal markers (`eGFR`, `Cre`) typically dominate under `pr_auc`. Under `f2`,
procedure flags that boost recall at tuned thresholds may rank higher even if PR-AUC drop is modest.
LOCO is **marginal** — correlated pairs (e.g. `eGFR` and `Cre`) can each look weaker than they are jointly.

**Caveats.** Test-set readout is transparent but optimistic if you iterate. Each ablation refits TabPFN
(×3 objectives). Cap via `LOCO_MAX_FEATURES` on Kaggle cloud runs; set `LOCO_SCORINGS = ["pr_auc"]` to
smoke-test before a full run.

## 8. Exact SHAP via masked forward passes

Two complementary views:

1. **§8a — Probability SHAP (local):** permutation Shapley values on \(P(\text{positive})\) for the top-`SHAP_TOP_K`
   `pr_auc`-LOCO features. Rich per-patient beeswarm plots; threshold-free.
2. **§8b — Coalition-metric SHAP (objective-aligned):** for each objective (`pr_auc`, `f1`, `f2`), Shapley values
   on the **global metric** over explained test rows when features are revealed vs background-masked — **no refit**,
   using the §5 context model. Universe = top-`SHAP_OBJECTIVE_UNIVERSE` features from the matching LOCO objective.

For tractability, probability SHAP explains the **top-`SHAP_TOP_K` LOCO (`pr_auc`) features** on a handful of
test rows (positives first). Coalition SHAP reuses the same instance/background sampling per objective.

def exact_shap(predict_fn, X_background, X_explain, feat_subset, *, n_perm=40, seed=42):
    """Permutation SHAP via masked forward passes (unbiased; exact in the permutation limit)."""
    rng = np.random.default_rng(seed)
    m = X_explain.shape[0]
    k = len(feat_subset)
    phi = np.zeros((m, k), dtype=float)
    feat_subset = np.asarray(feat_subset)

    for p in range(n_perm):
        bg = X_background[rng.integers(0, X_background.shape[0])]
        perm = rng.permutation(k)
        cur = X_explain.copy()
        cur[:, feat_subset] = bg[feat_subset]          # mask all subset features to background
        prev = predict_fn(cur)
        for pos in perm:
            f = feat_subset[pos]
            cur[:, f] = X_explain[:, f]                # reveal this feature's true value
            now = predict_fn(cur)
            phi[:, pos] += (now - prev)
            prev = now
        if (p + 1) % 10 == 0 or p + 1 == n_perm:
            print(f"  SHAP permutation {p+1}/{n_perm}")
    return phi / n_perm


def _coalition_probas(clf, bg_row, X_exp, feat_arr, revealed):
    """Mask feat_arr \\ revealed to background; keep other columns at true values."""
    cur = X_exp.copy()
    for pos, f in enumerate(feat_arr):
        if pos not in revealed:
            cur[:, f] = bg_row[f]
    return pos_proba(clf, cur)


def coalition_metric_shap(clf, X_bg, X_exp, y_exp, feat_subset, *, metric, n_perm=40, seed=42):
    """Shapley values for a global pr_auc / f1 / f2 on the explained test cohort (no refit)."""
    rng = np.random.default_rng(seed)
    feat_arr = np.asarray(feat_subset)
    k = len(feat_arr)
    phi = np.zeros(k, dtype=float)

    def v(revealed):
        vals = []
        for _ in range(min(3, len(X_bg))):
            bg = X_bg[rng.integers(0, len(X_bg))]
            probas = _coalition_probas(clf, bg, X_exp, feat_arr, revealed)
            vals.append(metric_score(y_exp, probas, metric))
        return float(np.mean(vals))

    for p in range(n_perm):
        perm = rng.permutation(k)
        revealed = set()
        prev = v(revealed)
        for pos in perm:
            revealed.add(int(pos))
            now = v(revealed)
            phi[pos] += now - prev
            prev = now
        if (p + 1) % 10 == 0 or p + 1 == n_perm:
            print(f"    coalition SHAP[{metric}] {p+1}/{n_perm}")
    return phi / n_perm

### 8.1 How to read the SHAP figures

**§8a — Probability SHAP (beeswarm / mean \|SHAP\|).** Exact permutation Shapley values on the top-`SHAP_TOP_K`
`pr_auc`-LOCO features. For each explained test row, we mask absent features to a **background** batch from
training and record how \(P(\text{stent thrombosis})\) changes when a feature is revealed. Threshold-free;
best for **local** direction-of-effect plots.

- **Mean \|SHAP\| bars:** average absolute push on \(P(\text{positive})\) across explained patients.
- **Beeswarm:** dot position = SHAP value; colour = normalized feature value for that patient.

**§8b — Coalition-metric SHAP (three panels).** One panel per objective (`pr_auc`, `f1`, `f2`). Each bar is the
Shapley value of the **global metric** on the explained cohort when a feature is revealed vs background-masked,
using the fixed §5 context model (forward passes only). Universe = top-`SHAP_OBJECTIVE_UNIVERSE` from the
**matching LOCO objective** — so `f2`-SHAP can rank different features than `pr_auc`-SHAP.

**Compare LOCO vs SHAP under the same objective.** LOCO refits without the column; SHAP masks without refit.
Agreement on top features supports robust importance; disagreement often flags correlation or context effects.

**Caveats.** Coalition SHAP averages over background rows and permutations (`SHAP_N_PERM`). Probability SHAP
explains only the LOCO subspace — not full 81 features. Neither method is causal. Increase `SHAP_N_PERM` on
GPU for lower variance.

## 9. Blending TabPFN with classical models

**Hypothesis.** TabPFN (transformer-based in-context Bayesian inference) and gradient-boosted / linear / bagging models make **different mistakes** on rare events, so a **convex blend** of their probabilities should match or beat any single learner on test PR-AUC.

We test the hypothesis with:

- **Six base learners** — `tabpfn` plus five classical models from `../../failed_hypothesis/baseline_blending.ipynb`: logistic regression (`lr`), random forest (`rf`), CatBoost (`cat`), XGBoost (`xgb`), LightGBM (`lgb`). All classical bases are wrapped in `CalibratedClassifierCV(sigmoid)` so their probabilities live on a comparable scale.
- **Four blend strategies** — `uniform` (equal weights), `slsqp` (scipy convex optimisation on the simplex), `meta_lr_softmax` (logistic stacking, weights = softmax of coefficients), and `optuna` (TPE search over a Dirichlet-parameterised simplex with the model **subset** itself as a hyperparameter, so it can pick 2, 3, ..., or 6 models). The Optuna study returns weights that are literally `study.best_params`.
- **Honest evaluation** — every blend's weights are learned on **out-of-fold (OOF)** training probabilities (same `StratifiedKFold(n_splits=BLEND_N_SPLITS, random_state=RANDOM_STATE)` partition for every base). Test predictions come from each base refit on the full `X_train`. The frozen test set is never seen during weight learning.

### 9.2 Learning the blend weights

Four weight-learning strategies are run on the OOF matrix:

1. **`uniform`** — equal weighting, `w_i = 1/k`. Pure baseline.
2. **`slsqp`** — scipy SLSQP minimises `-AveragePrecision` subject to `sum(w)=1, w>=0`. Continuous optimum on the simplex.
3. **`meta_lr_softmax`** — a `LogisticRegression(class_weight="balanced")` fit on `P_oof_matrix`. Reported as a renormalised non-negative weight via `softmax(coefs)`; the *fitted* meta-learner is also evaluated separately as `stacking[meta_lr]` further down.
4. **`optuna`** — TPE search with `n_trials=BLEND_OPTUNA_TRIALS`. Each trial proposes one `w_{name}` (Float) and one `use_{name}` (Int 0/1) per base; the mask enforces "at least `BLEND_MIN_MODELS` models active" (the user's "two, three, or more" constraint). Weights of inactive models are zeroed, the active ones are projected onto the simplex, and the trial value is the OOF PR-AUC of the resulting blend. Because each weight is literally an Optuna hyperparameter, `study.best_params` is directly readable.

########## CELL 31 [code] ##########
def _simplex(w, eps=1e-12):
    w = np.clip(np.asarray(w, dtype=float), 0.0, None)
    s = w.sum()
    return w / s if s > eps else np.full_like(w, 1.0 / len(w))


def learn_uniform(n_models):
    return np.full(n_models, 1.0 / n_models)


def learn_slsqp(P_oof_mat, y):
    n = P_oof_mat.shape[1]
    x0 = np.full(n, 1.0 / n)
    cons = [{"type": "eq", "fun": lambda w: w.sum() - 1.0}]
    bnds = [(0.0, 1.0)] * n
    res = _scipy_minimize(
        lambda w: -average_precision_score(y, P_oof_mat @ w),
        x0=x0, method="SLSQP", bounds=bnds, constraints=cons,
        options={"maxiter": 300, "ftol": 1e-9},
    )
    return _simplex(res.x)


def learn_meta_lr(P_oof_mat, y, *, seed=RANDOM_STATE):
    """Stack with LR on OOF probas. Return softmax(coefs) weights AND the fitted model."""
    lr = LogisticRegression(
        C=1.0, penalty="l2", solver="lbfgs", max_iter=2000,
        class_weight="balanced", random_state=seed,
    )
    lr.fit(P_oof_mat, y)
    c = lr.coef_.ravel()
    w = np.exp(c - c.max())
    w = w / w.sum()
    return w, lr


def learn_optuna(P_oof_mat, y, base_names, *, n_trials=BLEND_OPTUNA_TRIALS,
                 min_models=BLEND_MIN_MODELS, seed=RANDOM_STATE):
    """TPE search over a Dirichlet simplex with a subset mask.

    Each trial proposes per-model `w_{name}` ∈ [1e-3, 1] and `use_{name}` ∈ {0,1}.
    If the mask selects fewer than `min_models` models, we force-activate the top-`min_models`
    by raw weight magnitude. Weights of inactive models are zeroed; active weights are
    projected onto the simplex. Objective: OOF PR-AUC.
    """
    n = len(base_names)
    optuna.logging.set_verbosity(optuna.logging.WARNING)

    def _weights_from_params(params):
        raw = np.array([params[f"w_{base_names[i]}"] for i in range(n)])
        mask = np.array([params[f"use_{base_names[i]}"] for i in range(n)], dtype=bool)
        if mask.sum() < min_models:
            forced = np.argsort(-raw)[:min_models]
            mask = np.zeros(n, dtype=bool); mask[forced] = True
        w = np.zeros(n, dtype=float)
        w[mask] = _simplex(raw[mask])
        return w

    def objective(trial):
        params = {}
        for i in range(n):
            params[f"w_{base_names[i]}"] = trial.suggest_float(f"w_{base_names[i]}", 1e-3, 1.0)
            params[f"use_{base_names[i]}"] = trial.suggest_int(f"use_{base_names[i]}", 0, 1)
        w = _weights_from_params(params)
        return average_precision_score(y, P_oof_mat @ w)

    study = optuna.create_study(
        direction="maximize", sampler=optuna.samplers.TPESampler(seed=seed),
    )
    study.optimize(objective, n_trials=n_trials, show_progress_bar=False)
    return _weights_from_params(study.best_params), study


def learn_blend_weights(P_oof_mat, y, base_names, method, **kwargs):
    """Unified entry point. method in {'uniform','slsqp','meta_lr','optuna'}."""
    n = P_oof_mat.shape[1]
    if method == "uniform":
        return learn_uniform(n), None
    if method == "slsqp":
        return learn_slsqp(P_oof_mat, y), None
    if method == "meta_lr":
        w, model = learn_meta_lr(P_oof_mat, y, **kwargs)
        return w, model
    if method == "optuna":
        return learn_optuna(P_oof_mat, y, base_names, **kwargs)
    raise ValueError(f"Unknown blend method: {method}")

def stacking_oof_predict(P_oof_mat, y, *, n_splits=BLEND_N_SPLITS, seed=RANDOM_STATE):
    """Honest OOF stacking: refit meta-LR inside each fold of P_oof_matrix."""
    skf = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=seed)
    oof = np.zeros(len(y), dtype=float)
    for tr, va in skf.split(P_oof_mat, y):
        m = LogisticRegression(
            C=1.0, penalty="l2", solver="lbfgs", max_iter=2000,
            class_weight="balanced", random_state=seed,
        )
        m.fit(P_oof_mat[tr], y[tr])
        oof[va] = m.predict_proba(P_oof_mat[va])[:, 1]
    return oof

### 9.5 Sweeping the weight-learning objective

§9.2 optimises weights against a single objective (OOF PR-AUC). Different deployment contexts care about different metrics, so this subsection runs the same weight-learning recipe under **every rational objective** and reports the best strategy per objective plus a global champion.

The objective registry covers two families:

- **Ranking objectives** (threshold-independent) — `pr_auc`, `roc_auc`.
- **Threshold objectives** (`select_threshold`-driven) — `f1`, `f2`, `fbeta_{THRESHOLD_BETA}`, `recall_at_precision` (maximise recall subject to precision >= `MIN_PRECISION`), `target_recall` (maximise precision subject to recall >= `TARGET_RECALL`).

For each objective we re-evaluate the four blend strategies from §9.2:

- `uniform` and `meta_lr_softmax` produce **objective-independent weights**; only their deployment threshold changes per objective.
- `slsqp` and `optuna` are **re-optimised per objective** — the OOF objective value is the optimisation target.

To avoid test peeking, the deployment threshold for each (objective, strategy) is chosen **strictly on OOF train scores** and then applied to test. Ranking objectives use F2 as the deployment threshold (matches §6b) since their reported test_score is AUC and threshold-independent.

########## CELL 37 [code] ##########
BLEND_OBJECTIVES = {
    "pr_auc":  {"kind": "ranking",   "score_fn": average_precision_score},
    "roc_auc": {"kind": "ranking",   "score_fn": roc_auc_score},
    "f1":      {"kind": "threshold", "strategy": "f1",                  "beta": 1.0,             "report": "f1"},
    "f2":      {"kind": "threshold", "strategy": "f2",                  "beta": 2.0,             "report": "f2"},
    f"fbeta_{THRESHOLD_BETA:g}": {
                "kind": "threshold", "strategy": "fbeta",               "beta": THRESHOLD_BETA,  "report": f"f{THRESHOLD_BETA:g}"},
    "recall_at_precision": {
                "kind": "threshold", "strategy": "recall_at_precision", "beta": 2.0,             "report": "recall"},
    "target_recall": {
                "kind": "threshold", "strategy": "target_recall",       "beta": 2.0,             "report": "precision"},
}
BLEND_MULTI_OPTUNA_TRIALS = 200


def oof_objective_value(y, oof_scores, obj_name):
    """Scalar OOF score for `obj_name` — used as the SLSQP / Optuna optimisation target."""
    obj = BLEND_OBJECTIVES[obj_name]
    if obj["kind"] == "ranking":
        return float(obj["score_fn"](y, oof_scores))
    _, info = select_threshold(
        y, oof_scores, strategy=obj["strategy"], beta=obj["beta"],
        min_precision=MIN_PRECISION, target_recall=TARGET_RECALL,
    )
    return float(info[obj["report"]])


def oof_threshold_for(y, oof_scores, obj_name):
    """Deployment threshold picked on OOF for `obj_name` (ranking objectives fall back to F2)."""
    obj = BLEND_OBJECTIVES[obj_name]
    strategy = obj.get("strategy", "f2")
    beta = obj.get("beta", 2.0)
    return select_threshold(
        y, oof_scores, strategy=strategy, beta=beta,
        min_precision=MIN_PRECISION, target_recall=TARGET_RECALL,
    )[0]


def deployment_test_score(y_te, test_scores, threshold, obj_name):
    """`obj_name`'s metric on test, computed at the OOF-chosen `threshold` (no test peeking)."""
    obj = BLEND_OBJECTIVES[obj_name]
    if obj["kind"] == "ranking":
        return float(obj["score_fn"](y_te, test_scores))
    pred = (test_scores >= threshold).astype(int)
    rep = obj["report"]
    if rep == "recall":
        return float(recall_score(y_te, pred, zero_division=0))
    if rep == "precision":
        return float(precision_score(y_te, pred, zero_division=0))
    if rep == "f1":
        return float(f1_score(y_te, pred, zero_division=0))
    return float(fbeta_score(y_te, pred, beta=obj["beta"], zero_division=0))


def _test_battery(scores, threshold):
    """Standard metric battery on test at a fixed (OOF-chosen) threshold."""
    pred = (scores >= threshold).astype(int)
    return {
        "test_pr_auc": float(average_precision_score(y_test, scores)),
        "test_roc_auc": float(roc_auc_score(y_test, scores)),
        "test_f1": float(f1_score(y_test, pred, zero_division=0)),
        "test_f2": float(fbeta_score(y_test, pred, beta=2.0, zero_division=0)),
        "test_precision": float(precision_score(y_test, pred, zero_division=0)),
        "test_recall": float(recall_score(y_test, pred, zero_division=0)),
    }


def learn_slsqp_for(P_oof_mat, y, obj_name):
    n = P_oof_mat.shape[1]
    x0 = np.full(n, 1.0 / n)
    cons = [{"type": "eq", "fun": lambda w: w.sum() - 1.0}]
    bnds = [(0.0, 1.0)] * n
    res = _scipy_minimize(
        lambda w: -oof_objective_value(y, P_oof_mat @ w, obj_name),
        x0=x0, method="SLSQP", bounds=bnds, constraints=cons,
        options={"maxiter": 300, "ftol": 1e-9},
    )
    return _simplex(res.x)


def learn_optuna_for(P_oof_mat, y, base_names, obj_name, *,
                     n_trials=BLEND_MULTI_OPTUNA_TRIALS,
                     min_models=BLEND_MIN_MODELS, seed=RANDOM_STATE):
    n = len(base_names)
    optuna.logging.set_verbosity(optuna.logging.WARNING)

    def _w(params):
        raw = np.array([params[f"w_{base_names[i]}"] for i in range(n)])
        mask = np.array([params[f"use_{base_names[i]}"] for i in range(n)], dtype=bool)
        if mask.sum() < min_models:
            forced = np.argsort(-raw)[:min_models]
            mask = np.zeros(n, dtype=bool); mask[forced] = True
        w = np.zeros(n, dtype=float)
        w[mask] = _simplex(raw[mask])
        return w

    def objective(trial):
        params = {}
        for i in range(n):
            params[f"w_{base_names[i]}"] = trial.suggest_float(f"w_{base_names[i]}", 1e-3, 1.0)
            params[f"use_{base_names[i]}"] = trial.suggest_int(f"use_{base_names[i]}", 0, 1)
        return oof_objective_value(y, P_oof_mat @ _w(params), obj_name)

    study = optuna.create_study(direction="maximize",
                                sampler=optuna.samplers.TPESampler(seed=seed))
    study.optimize(objective, n_trials=n_trials, show_progress_bar=False)
    return _w(study.best_params), study

## 10. Feature selection comparison: LOCO vs SHAP vs FFS

Three different ways to ask "which features matter?" — and they often disagree because they answer **different questions**.

| | **LOCO** (Leave-One-Covariate-Out) | **SHAP** (permutation, masked forward passes) | **FFS** (Forward Feature Selection) |
|---|---|---|---|
| **Question** | How much does the model *lose* if I **drop** this one column? | What is this feature's **average marginal contribution** to each prediction? | Which **small set** of columns gives the best held-out score when added greedily? |
| **What it measures** | *Conditional* importance — unique information the feature carries **given all others remain** | *Marginal* Shapley value — average change in output when the feature is revealed vs a background | *Synergistic* subset quality — features that **work well together** in the model |
| **Granularity** | One global score per feature | Signed value **per row** (we aggregate with mean \|SHAP\|) | One ordered list of K features (path-dependent) |
| **Model interaction** | Refits TabPFN with column removed | Forward passes only (masks to background) | Refits TabPFN on growing subsets |
| **Cost (d features, K selected)** | O(d) fits | O(n_perm × k × n_instances) forward passes | O(K × d) fits |
| **Strengths** | Fast global ranking; highlights features the model *cannot replace* | Rich, local explanations; threshold-free | Finds compact subsets tuned to a deployment metric |
| **Pitfalls** | **Undervalues correlated features** — if A and B carry the same signal, dropping either alone barely hurts | Can **over-credit correlated features** (credit split across coalitions); expensive at full d | **Greedy & path-dependent** — early picks lock in; misses features that only help in combination |

**This section's workflow:** §7–§8 already ranked features under `pr_auc`, `f1`, and `f2` for LOCO and coalition SHAP. Here we extract top-`FEATURE_TOPK` lists, run FFS under the same three objectives, refit TabPFN on each subset (plus the **union**), and compare test metrics against the **baseline** (all features, §5).

### 10.1 Extracting the top-K feature lists

§7 already produced **LOCO** rankings for `pr_auc`, `f1`, and `f2`. §8b produced matching
**coalition SHAP** rankings. Here we take top-`FEATURE_TOPK` from each (plus FFS below).
FFS runs **three** greedy holdout searches with the same objectives. Each FFS run continues until
the holdout metric reaches `FFS_TARGET_SCORE` (default 1.0) or `FEATURE_TOPK` steps are exhausted.

FEATURE_TOPK = 20
FFS_HOLDOUT_FRAC = 0.2
FFS_SCORINGS = ["pr_auc", "f1", "f2"]
FFS_TARGET_SCORE = 1.0            # stop once holdout metric reaches this (or FEATURE_TOPK)
FS_SEED = RANDOM_STATE


def ffs_tabpfn(X_tr, y_tr, names, *, k=FEATURE_TOPK, holdout_frac=FFS_HOLDOUT_FRAC,
               scoring="pr_auc", target_score=FFS_TARGET_SCORE, seed=FS_SEED):
    """Greedy forward feature selection with TabPFN on a single stratified holdout."""
    n_feat = X_tr.shape[1]
    k = min(k, n_feat)

    X_fit, X_hold, y_fit, y_hold = train_test_split(
        X_tr, y_tr, test_size=holdout_frac, stratify=y_tr, random_state=seed,
    )

    def _score(y_true, probas):
        return metric_score(y_true, probas, scoring)

    selected, step_rows = [], []
    candidates = set(range(n_feat))
    prev_sc = None
    fit_count = 0

    for step in range(1, k + 1):
        best_j, best_sc = None, -np.inf
        n_cand = len(candidates)
        for j in sorted(candidates):
            cols = selected + [j]
            m = make_tabpfn(seed=seed + step * 1000 + j)
            m.fit(X_fit[:, cols], y_fit)
            sc = _score(y_hold, pos_proba(m, X_hold[:, cols]))
            fit_count += 1
            if fit_count % 20 == 0:
                print(f"  FFS[{scoring}] fit {fit_count} (step {step}, {n_cand} candidates)")
            if sc > best_sc:
                best_j, best_sc = j, sc

        selected.append(best_j)
        candidates.remove(best_j)
        marginal = np.nan if prev_sc is None else float(best_sc - prev_sc)
        step_rows.append({
            "step": step,
            "feature": names[best_j],
            "index": best_j,
            "holdout_score": round(float(best_sc), 4),
            "marginal_gain": round(marginal, 4) if not np.isnan(marginal) else np.nan,
            "scoring": scoring,
        })
        print(f"  FFS[{scoring}] step {step}: + {names[best_j]}  "
              f"holdout={best_sc:.4f}  Δ={marginal if not np.isnan(marginal) else '—'}")
        prev_sc = best_sc

        if best_sc >= target_score - 1e-9:
            print(f"  FFS[{scoring}] stop: holdout {scoring} reached {best_sc:.4f} "
                  f"(target={target_score})")
            break

    selected_names = [names[j] for j in selected]
    return selected_names, pd.DataFrame(step_rows)

### 10.1b How to read the FFS figures

**What FFS does.** Starting from an empty feature set, each step adds the one column that most
improves a **holdout score** on a stratified 20% slice of `X_train`. TabPFN is refit from scratch
at every candidate evaluation — this is the most expensive selector but directly optimises model performance.

**Left figure — Learning curves (`tabpfn_fs_ffs_curves.png`)**
- **One panel per objective:** `pr_auc` (ranking), `f1` (balanced precision/recall), `f2` (recall-leaning).
- **X-axis:** greedy step (1 = first feature added).
- **Y-axis:** holdout score after that step. For `f1`/`f2` the holdout threshold is tuned with
  `select_threshold` on the holdout scores each time — same logic as deployment in §5.
- **Stop rule:** selection continues step-by-step until the holdout score hits `FFS_TARGET_SCORE`
  (1.0 for `pr_auc`, `f1`, and `f2`) or `FEATURE_TOPK` is reached — whichever comes first.
  The dashed horizontal line marks that target on each panel.
- **Sudden jumps** (e.g. when `Cre` enters) indicate a feature that unlocks a lot of holdout signal,
  often jointly with features already selected.

**Right figure — Selected features (`tabpfn_fs_ffs_features.png`)**
- **Bar length:** step at which each feature was chosen (1 = picked first).
- **Compare panels:** `pr_auc`-FFS favours ranking power; `f2`-FFS may pick features that help recall
  on the holdout even if PR-AUC is flat. Overlap with LOCO/SHAP lists is informative but not guaranteed —
  FFS is path-dependent and greedy.

**Caveats.** Holdout scores can hit 1.0 with few positives (optimistic). Always validate on the
**frozen test set** in §10.2. FFS order matters: a feature picked early for `pr_auc` may differ from
what LOCO would rank first because FFS sees **joint** contributions.

### 10.2 Refit TabPFN on each subset

For each feature set we drop all other columns from the raw matrices, tune the decision threshold via OOF on `X_train` (same strategy as §5), refit TabPFN on the full training subset, and evaluate on the frozen test set. The **baseline** row reuses the §5 `y_prob` and `THRESHOLD` without refitting.

########## CELL 43 [code] ##########
def evaluate_feature_subset(name, feat_names):
    """Tune threshold OOF, refit TabPFN on feat_names subset, return metrics + test scores."""
    feat_idx = [feature_names.index(f) for f in feat_names]
    Xtr_sub = X_train[:, feat_idx]
    Xte_sub = X_test[:, feat_idx]

    print(f"\n[{name}] {len(feat_names)} features — OOF threshold tuning ...")
    oof_sub = oof_pos_proba(
        make_tabpfn, Xtr_sub, y_train,
        n_splits=THRESHOLD_CV_SPLITS, seed=RANDOM_STATE,
    )
    thr, thr_info = select_threshold(
        y_train, oof_sub, strategy=THRESHOLD_STRATEGY, beta=THRESHOLD_BETA,
        min_precision=MIN_PRECISION, target_recall=TARGET_RECALL,
    )
    print(f"[{name}] threshold={thr:.4f} | OOF " +
          " ".join(f"{k}={v:.3f}" for k, v in thr_info.items()))

    t0 = time.time()
    m = make_tabpfn(); m.fit(Xtr_sub, y_train)
    p_test = pos_proba(m, Xte_sub)
    print(f"[{name}] refit {time.time()-t0:.1f}s | test PR-AUC={average_precision_score(y_test, p_test):.4f}")

    pred = (p_test >= thr).astype(int)
    metrics = {
        "variant": name,
        "n_features": len(feat_names),
        "threshold": thr,
        "test_pr_auc": float(average_precision_score(y_test, p_test)),
        "test_roc_auc": float(roc_auc_score(y_test, p_test)),
        "test_f1": float(f1_score(y_test, pred, zero_division=0)),
        "test_f2": float(fbeta_score(y_test, pred, beta=2.0, zero_division=0)),
        "test_precision": float(precision_score(y_test, pred, zero_division=0)),
        "test_recall": float(recall_score(y_test, pred, zero_division=0)),
    }
    return metrics, p_test

## 11. Notes

- **Regression.** For a continuous target, swap `TabPFNClassifier` → `TabPFNRegressor` (`from tabpfn import
  TabPFNRegressor`), drop the threshold/`balance_probabilities` logic, and score with RMSE / R². LOCO and the
  masked-forward-pass SHAP transfer directly (use the regressor's `predict` in `predict_fn`).
- **Scaling up (TabPFN-3).** For very large tables (up to ~1M rows) use the **v3** engine, which adds
  **row-chunking** and a **compact KV-cache** for memory; v2.5 (used here) is sufficient for VLST.
- **Why no manual preprocessing.** TabPFN was pretrained to handle messy, heterogeneous, partially-missing
  tabular data, so external scaling / one-hot encoding tends to hurt rather than help.
- **Cost of interpretability.** LOCO is `O(n_features)` forward passes; permutation SHAP is
  `O(n_perm × k)` forward passes. Both are cheap relative to retraining a gradient-boosted model, which is the
  whole point of a training-free model. Increase `SHAP_N_PERM` / `SHAP_N_INSTANCES` on GPU for tighter estimates.
- **Kaggle.** See **§0**. Prefer **GPU + local TabPFN** (`USE_TABPFN_CLIENT=False` is set automatically when
  CUDA is available). Outputs land in `/kaggle/working/modeling_tabpfn/`. If you must use the cloud client,
  raise `LOCO_MAX_FEATURES` gradually — each LOCO step triggers a separate API fit.
