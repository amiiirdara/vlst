# Data Preprocessing for VLST Dataset

## Overview

This notebook prepares the VLST (Very Late Stent Thrombosis) data for modeling, based on findings from the EDA. It implements a reproducible, **leak-aware** pipeline that:

1. **Loads raw data** and drops identifiers, **leakage columns**, and duplicate rows
2. **Handles missing values** (imputation)
3. **Encodes categorical variables**
4. **Splits data** into train/test (stratified, frozen test holdout)
5. **Transforms continuous features** (scaling fit on train only)
6. **Saves preprocessed datasets and artifacts** for the modeling phase

### EDA Summary (from `../../analyzes/eda.ipynb`)

- **Target**: `Stent thrombosis` (binary: 0/1, ~1.8% positive rate)
- **Leakage**: `Time since stent implantation` is dropped here (strong label coupling; not a fair pre-event predictor)
- **Features**: Binary, continuous, and **stent brand** (canonicalized from mislabeled `Stent type-SES` text; PES/ZES/EVS stay as 0/1 flags)
- **Paths**: Raw data `data/raw/VLST.csv`; outputs to `data/processed/` (resolved from repo root)

## 2b. Stent columns (brand text + drug-eluting flags)

The column **`Stent type-SES`** in the raw file stores **stent product names** (e.g. Partner, Resolute), not a sirolimus-eluting (SES) binary. **`PES`**, **`ZES`**, and **`EVS`** are the actual drug-eluting type indicators (0/1).

We:
1. Canonicalize free-text brands → **`stent_brand`**
2. Collapse rare brands to **`other`** (keeps OHE small)
3. Coerce **PES / ZES / EVS** to integers in `{0, 1}`

########## CELL 6 [code] ##########
def canonicalize_stent_brand(value):
    """Normalize free-text stent product names."""
    if pd.isna(value) or str(value).strip() == "":
        return "missing"
    s = str(value).strip().replace("：", ":").lower()
    s = re.sub(r"\s+", "", s)
    if ":" in s:
        s = s.split(":")[-1]
    for sep in ("，", ",", "/"):
        if sep in s:
            s = s.split(sep)[0]
    aliases = {
        "xiencex": "xiencev",
        "resolut": "resolute",
        "parnter": "partner",
        "endeavor": "endeavor",
        "cypher": "cypher",
    }
    return aliases.get(s, s)


def collapse_rare_brands(series, min_count):
    counts = series.value_counts()
    rare = set(counts[counts < min_count].index)
    if not rare:
        return series
    return series.where(~series.isin(rare), "other")


if STENT_BRAND_RAW_COL in df.columns:
    raw_nuniq = df[STENT_BRAND_RAW_COL].nunique()
    df[STENT_BRAND_COL] = df[STENT_BRAND_RAW_COL].map(canonicalize_stent_brand)
    df = df.drop(columns=[STENT_BRAND_RAW_COL])
    df[STENT_BRAND_COL] = collapse_rare_brands(
        df[STENT_BRAND_COL], STENT_BRAND_MIN_COUNT
    )
    print(
        f"Stent brand: {raw_nuniq} raw text values -> "
        f"{df[STENT_BRAND_COL].nunique()} categories "
        f"(min_count={STENT_BRAND_MIN_COUNT})"
    )
    print(df[STENT_BRAND_COL].value_counts())
else:
    print(f"Note: {STENT_BRAND_RAW_COL} not found (already renamed?)")

for col in STENT_TYPE_FLAG_COLS:

    bad = ~s.isin([0, 1])

            f"{col}: expected 0/1 after coercion, got {df.loc[bad, col].unique()[:10]}"
        )
    df[col] = s
    print(f"{col}: {s.value_counts().to_dict()}")

print(f"Shape after stent encoding: {df.shape}")

## 3. Feature Categorization

Separate columns into numeric (binary + continuous) and categorical, consistent with EDA.

########## CELL 8 [code] ##########
# All feature columns (exclude target)
feature_cols = [c for c in df.columns if c != TARGET_COL]
numeric_cols = df[feature_cols].select_dtypes(include=[np.number]).columns.tolist()
cat_cols = df[feature_cols].select_dtypes(include=["object"]).columns.tolist()

# Binary: numeric with only 0/1 (and possibly NaN)
binary_cols = []
for c in numeric_cols:
    uniq = df[c].dropna().unique()
    if len(uniq) <= 2 and set(uniq).issubset({0, 1}):
        binary_cols.append(c)
continuous_cols = [c for c in numeric_cols if c not in binary_cols]

# Drop zero-variance columns before building the preprocessor (must run before §5)
constant_cols = [c for c in feature_cols if df[c].nunique(dropna=False) <= 1]

    binary_cols = [c for c in binary_cols if c not in constant_cols]

## 5. Build Preprocessing Pipeline

- **Continuous**: Impute with median, then standardize (fit on train later).
- **Binary**: Impute with mode (most frequent 0/1).
- **Categorical**: Impute with mode, then one-hot encode (drop first to avoid collinearity in linear models).

########## CELL 12 [code] ##########
# Imputation + scaling/encoding (numeric scaled in step 7 after split)
imputer_cont = SimpleImputer(strategy="median")
imputer_bin = SimpleImputer(strategy="most_frequent")
imputer_cat = SimpleImputer(strategy="constant", fill_value="missing")
ohe = OneHotEncoder(drop="first", handle_unknown="ignore")

# ColumnTransformer for imputation + encoding (no scaling yet)
transformers = []
if continuous_cols:
    transformers.append(("num", imputer_cont, continuous_cols))
if binary_cols:
    transformers.append(("bin", imputer_bin, binary_cols))
if cat_cols:
    transformers.append(
        ("cat", Pipeline([("impute", imputer_cat), ("ohe", ohe)]), cat_cols)
    )

preprocessor = ColumnTransformer(
    transformers, remainder="drop", verbose_feature_names_out=False
)
print("Preprocessor (imputation + OHE for categorical):")
print(preprocessor)

## 11. Summary

Preprocessing is complete. For modeling you can:

- **NumPy**: `np.load('data/processed/X_train.npy')`, same for `X_test`, `y_train`, `y_test`.
- **DataFrames**: `pd.read_parquet('data/processed/train.parquet')` (or `train.csv` if parquet unavailable), same for test.
- **Feature names**: `pd.read_csv('data/processed/feature_names.csv')`.
- **Column roles**: `pd.read_csv('data/processed/column_config.csv')`.
- **Inference**: Load `preprocessor.joblib` and `scaler.joblib` to transform new raw data the same way.

**Leakage**: `Time since stent implantation` is excluded in this notebook. Re-run preprocessing after changing raw data, then re-run modeling notebooks.

**Class imbalance**: ~1–2% positives. Prefer **PR-AUC**, recall/precision at a calibrated threshold, and **balanced accuracy** over raw accuracy in modeling.
