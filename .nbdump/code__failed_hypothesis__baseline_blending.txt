# Advanced Modeling (VLST)

This notebook is a clean, leak-aware rebuild of the previous workflow.

It answers and implements:
- why and how **calibration** helps,
- why we use a **three-way stratified split**,
- why a **CatBoost wrapper** can be useful,
- what **`scale_pos_weight`** is and when it helps,
- whether **average precision (PR-AUC)** is rational for imbalanced data,
- what the main modeling sections mean in the pipeline,
- model-wise **best threshold** search,
- **operational** metrics at a fixed deployment threshold (not only ranking metrics),
- **stability** under bootstrap resampling for rare positives,
- targeted **overfitting/leakage diagnostics** for suspiciously high ROC-AUC,
- **outer repeated stratified splits** on `X_train` with **per-variant median / p25 / p75** PR-AUC summaries (defaults rank by calibration stability, not test),
- **OOF-trained meta logistic** on uncalibrated merge-fit bases plus **secondary** isotonic/Platt calibration,
- **ensemble blends** via simplex **grids**, **SLSQP**, **min-weight** grids, **operational objectives** (recall at precision floor, \(F_\beta\)) on calibration, post-hoc blend calibration, **diversity heads** (`rf_b`, `xgb_b`), and in-sample meta stackers for comparison,
- **stratified bootstrap** PR-AUC / F1 in §10 for rare positives.

### Section map (notebook structure)

1. Setup, optional pip bootstrap, imports, CUDA/device flags  
2. Leakage guardrails and baseline checks  
3. Three-way stratified split (`fit` / early-stop / calibration)  
4. CatBoost wrapper and `scale_pos_weight` usage  
5. Individual models (LR, RF, CatBoost, XGB, LGB), selection, PR-AUC rationale  
6. Refit selected boosters and RF on merged `fit + early_stop`  
7. Sigmoid calibration into `base_models` / `cal_models`  
8. Ensemble blends (built in **§7** after outer splits: grids, SLSQP, meta, OOF meta, operational rows, post-hoc cal, diversity heads)  
8b. **Policy comparison** — 3 policies × cal/test + bootstrap (Phases 1 & 3)  
8c. **5-fold CV on train** — mean ± std validation PR-AUC (Phase 4; uses 70/30 split from preprocessing)  
9. Best threshold per calibrated model (calibration-fitted only)  
10. **Operational metrics** at the chosen blend + threshold (MCC, BA, confusion matrices, bootstrap stability, figures)  
11. Train / cal / test gaps and leakage-oriented diagnostics (+ figure)  
12. Save artifacts and final recommendations  

### Evaluation protocol (read this first)

| Role | Data | Used for |
|------|------|----------|
| **Test** | `X_test`, `y_test` (**30%**, frozen **within each run**; split from `DATA_MODE`) | **Final report only** — not for picking blends or thresholds |
| **Fit** | subset of `X_train` | Model weights, hyperparameter search |
| **Early stop** | subset of `X_train` | Booster stopping / grid AP during tuning |
| **Calibration** | subset of `X_train` | Probability calibration, blend weights, deployment threshold |

**Primary metrics** (rare positives ~1–2%): **PR-AUC** for ranking, then **recall / precision / F1 / MCC / balanced accuracy** at a threshold chosen on calibration. Raw **accuracy** is reported but **not** used for model or blend selection (majority-class baseline ~98%).

**Blend policy**: rank by `BLEND_RANK_METRIC` (default: median calibration PR-AUC across outer seeds). §10 operational row = first **convex** blend after that sort. §8 also shows an **exploratory** test-best convex row (optimistic; do not treat as unbiased).

## 1. Setup and data contract

Data policy (controlled by **`DATA_MODE`** in the next code cell — same pattern as `../modeling/rating/tabpfn_playground.ipynb`):

| `DATA_MODE` | Source | Train/test split |
|-------------|--------|------------------|
| **`"processed"`** | `.npy` arrays from `../modeling/preprocessing/preprocessing.ipynb` | **Fixed** split (`random_state=42` in preprocess) — same rows every run |
| **`"inline"`** | Raw `VLST.csv` preprocessed **inside this notebook** (same logic as `preprocessing.ipynb`) | **Fresh** stratified split each run when `SPLIT_RANDOM_STATE = None`; set an `int` to reproduce a specific split |

Additional rules (both modes):

- **Leak-aware:** `Time since stent implantation` is dropped at preprocess time.
- **`X_test`, `y_test` are frozen** within a run — final evaluation only, not for choosing among blend variants.
- **`X_train`** is ~**70%** of rows (`TEST_SIZE=0.30`); internally split into `fit`, `early_stop`, and `calibration` (defaults **15% / 15% / 15%** of train, stratified).
- Threshold search, calibration, and blend weights use **calibration** (and outer-seed stability columns), not test.

**Tip:** use `"processed"` when comparing to saved results / other notebooks; use `"inline"` when you want split variability or to avoid depending on a stale Kaggle dataset bundle.

def _canonicalize_stent_brand(value):
    if pd.isna(value) or str(value).strip() == "":
        return "missing"
    s = str(value).strip().replace("：", ":").lower()
    s = re.sub(r"\s+", "", s)
    if ":" in s:
        s = s.split(":")[-1]
    for sep in ("，", ",", "/"):
        if sep in s:
            s = s.split(sep)[0]
    aliases = {
        "xiencex": "xiencev",
        "resolut": "resolute",
        "parnter": "partner",
        "endeavor": "endeavor",
        "cypher": "cypher",
    }
    return aliases.get(s, s)


def _collapse_rare_brands(series, min_count):
    counts = series.value_counts()
    rare = set(counts[counts < min_count].index)
    if not rare:
        return series
    return series.where(~series.isin(rare), "other")


def _clean_raw_dataframe(df):
    meta = {}
    id_drop = [c for c in ID_COLS if c in df.columns]
    if id_drop:
        df = df.drop(columns=id_drop)
    meta["dropped_id_cols"] = id_drop

    leak_drop = [c for c in LEAKAGE_COLS if c in df.columns]
    if leak_drop:
        df = df.drop(columns=leak_drop)
    meta["dropped_leakage_cols"] = leak_drop

    n_before = len(df)
    df = df.drop_duplicates()
    meta["n_duplicate_rows_dropped"] = int(n_before - len(df))

    df[TARGET_COL] = pd.to_numeric(df[TARGET_COL], errors="coerce").astype("Int64")
    if df[TARGET_COL].isna().any():
        raise ValueError("Target contains non-numeric values after coercion")

    if STENT_BRAND_RAW_COL in df.columns:
        df[STENT_BRAND_COL] = df[STENT_BRAND_RAW_COL].map(_canonicalize_stent_brand)
        df = df.drop(columns=[STENT_BRAND_RAW_COL])
        df[STENT_BRAND_COL] = _collapse_rare_brands(df[STENT_BRAND_COL], STENT_BRAND_MIN_COUNT)

    for col in STENT_TYPE_FLAG_COLS:
        if col not in df.columns:
            continue
        s = pd.to_numeric(df[col], errors="coerce").fillna(0).astype(int)
        if (~s.isin([0, 1])).any():
            raise ValueError(f"{col}: expected 0/1 after coercion")
        df[col] = s

    meta["n_rows_after_clean"] = int(len(df))
    return df, meta


def _feature_columns(df):
    feature_cols = [c for c in df.columns if c != TARGET_COL]
    numeric_cols = df[feature_cols].select_dtypes(include=[np.number]).columns.tolist()
    cat_cols = df[feature_cols].select_dtypes(include=["object"]).columns.tolist()

    binary_cols = []
    for c in numeric_cols:
        uniq = df[c].dropna().unique()
        if len(uniq) <= 2 and set(uniq).issubset({0, 1}):
            binary_cols.append(c)
    continuous_cols = [c for c in numeric_cols if c not in binary_cols]

    constant_cols = [c for c in feature_cols if df[c].nunique(dropna=False) <= 1]
    if constant_cols:
        feature_cols = [c for c in feature_cols if c not in constant_cols]
        binary_cols = [c for c in binary_cols if c not in constant_cols]
        continuous_cols = [c for c in continuous_cols if c not in constant_cols]
        cat_cols = [c for c in cat_cols if c not in constant_cols]

    return feature_cols, binary_cols, continuous_cols, cat_cols


def _build_preprocessor(binary_cols, continuous_cols, cat_cols):
    imputer_cont = SimpleImputer(strategy="median")
    imputer_bin = SimpleImputer(strategy="most_frequent")
    imputer_cat = SimpleImputer(strategy="constant", fill_value="missing")
    ohe = OneHotEncoder(drop="first", handle_unknown="ignore")

    transformers = []
    if continuous_cols:
        transformers.append(("num", imputer_cont, continuous_cols))
    if binary_cols:
        transformers.append(("bin", imputer_bin, binary_cols))
    if cat_cols:
        transformers.append(
            ("cat", Pipeline([("impute", imputer_cat), ("ohe", ohe)]), cat_cols)
        )
    return ColumnTransformer(transformers, remainder="drop", verbose_feature_names_out=False)


def _drop_leakage_from_arrays(X_tr, X_te, names):
    fn = np.array(names)
    leak_mask = np.array([any(tok in str(n) for tok in DROP_FEATURES) for n in fn], dtype=bool)
    if not leak_mask.any():
        return X_tr, X_te, list(fn)
    return X_tr[:, ~leak_mask], X_te[:, ~leak_mask], fn[~leak_mask].tolist()


def _load_processed_arrays(processed_dir):
    processed_dir = Path(processed_dir)
    required = ["X_train.npy", "X_test.npy", "y_train.npy", "y_test.npy", "feature_names.csv"]
    missing = [name for name in required if not (processed_dir / name).is_file()]
    if missing:
        raise FileNotFoundError(
            f"Missing processed files in {processed_dir}: {missing}. "
            "Run preprocessing.ipynb or set DATA_MODE='inline'."
        )

    X_tr = np.load(processed_dir / "X_train.npy")
    X_te = np.load(processed_dir / "X_test.npy")
    y_tr = np.load(processed_dir / "y_train.npy")
    y_te = np.load(processed_dir / "y_test.npy")
    names = pd.read_csv(processed_dir / "feature_names.csv")["feature_name"].tolist()
    X_tr, X_te, names = _drop_leakage_from_arrays(X_tr, X_te, names)

    manifest_path = processed_dir / "preprocess_manifest.json"
    if manifest_path.is_file():
        with open(manifest_path, encoding="utf-8") as f:
            manifest = json.load(f)
    else:
        manifest = {"mode": "processed", "processed_dir": str(processed_dir)}
    manifest["mode"] = "processed"
    manifest["processed_dir"] = str(processed_dir)

    return {
        "X_train": X_tr,
        "X_test": X_te,
        "y_train": y_tr,
        "y_test": y_te,
        "feature_names": names,
        "manifest": manifest,
        "split_random_state": manifest.get("random_state"),
    }


def _preprocess_inline(raw_path, *, test_size, split_random_state):
    if split_random_state is None:
        split_random_state = secrets.randbelow(2 ** 31 - 1)

    raw_path = Path(raw_path)
    df = pd.read_csv(raw_path)
    df, clean_meta = _clean_raw_dataframe(df)

    feature_cols, binary_cols, continuous_cols, cat_cols = _feature_columns(df)
    preprocessor = _build_preprocessor(binary_cols, continuous_cols, cat_cols)

    X = df[feature_cols].copy()
    y = df[TARGET_COL].copy()
    X_tr, X_te, y_tr, y_te = train_test_split(
        X,
        y,
        test_size=test_size,
        random_state=int(split_random_state),
        stratify=y,
    )
    y_tr = y_tr.astype(np.int64).to_numpy()
    y_te = y_te.astype(np.int64).to_numpy()

    X_tr_enc = preprocessor.fit_transform(X_tr)
    X_te_enc = preprocessor.transform(X_te)
    names = preprocessor.get_feature_names_out().tolist()

    scaler = StandardScaler()
    X_tr_scaled = scaler.fit_transform(X_tr_enc)
    X_te_scaled = scaler.transform(X_te_enc)

    manifest = {
        **clean_meta,
        "mode": "inline",
        "raw_path": str(raw_path),
        "test_size": float(test_size),
        "random_state": int(split_random_state),
        "stent_brand_col": STENT_BRAND_COL,
        "stent_brand_min_count": STENT_BRAND_MIN_COUNT,
        "stent_type_flag_cols": STENT_TYPE_FLAG_COLS,
        "n_features_after_preprocess": int(len(names)),
        "train_positives": int((y_tr == 1).sum()),
        "test_positives": int((y_te == 1).sum()),
    }

    return {
        "X_train": np.asarray(X_tr_scaled, dtype=np.float64),
        "X_test": np.asarray(X_te_scaled, dtype=np.float64),
        "y_train": y_tr,
        "y_test": y_te,
        "feature_names": names,
        "manifest": manifest,
        "split_random_state": int(split_random_state),
    }

## 3. Three-way stratified split inside training

What it is:
- **fit**: model fitting and CV search.
- **early_stop**: for booster early stopping decisions.
- **calibration**: for post-hoc probability calibration and threshold tuning.

Why useful:
- avoids tuning booster iterations on the same data used to fit calibrators,
- avoids threshold selection on test,
- keeps probability quality and decision policy closer to deployment reality.

**Slice sizes:** `FRAC_CAL` / `FRAC_ES` live in the next code cell. Defaults are **15% / 15%** of `X_train` (stratified), giving ~70% for fit — a balance between enough positives in calibration for stable thresholds/blends and enough data in fit + early_stop for tuning.


########## CELL 8 [code] ##########
# ---------------------------------------------------------------------------
# Three-way stratified split + pipeline stability **configuration**
#
# FRAC_CAL / FRAC_ES: stratified fractions of X_train only (test stays frozen).
# 15% / 15% matches the original stable protocol (~70% fit, ~15% ES, ~15% cal).
# Smaller FRAC_CAL puts more positives in fit+ES but makes cal metrics noisier.
# ---------------------------------------------------------------------------
FRAC_CAL = 0.15
FRAC_ES = 0.15

# Reference seed used for: (1) the initial split shown in `split_stats`, (2) the

### 3b. Pipeline stability configuration and reusable helpers

The functions in the next code cell support:

- **Stratified bootstrap** of PR-AUC / F1 (resample positives and negatives separately) so rare-class test/calibration rows are not treated as i.i.d. when they are highly stratified.
- **Aggregation of `blend_table` across outer seeds** (median / p25 / p75 and a simple lower-confidence style score on calibration PR-AUC).
- **Post-hoc calibration** of a 1-D score (isotonic when sample sizes allow, else Platt / logistic on `p.reshape(-1,1)`).
- **Out-of-fold stacked base probabilities** on `X_merge` for training a meta-learner without reusing the same rows the bases were fit on (reduces meta overfitting vs fitting meta on in-sample `P_cal`).

All helpers are **pure** where possible (take arrays / DataFrames, return results) so outer loops stay readable.

def _blend(preds, w):
    """Convex combination of base-model positive-class probabilities.

    Defined at notebook scope so §10 can rebuild `p_cal_op` / `p_test_op` from stored
    weights. Logic matches the inner `_blend` inside `build_ensemble_blend_table`.
    """
    arr = np.vstack(preds).T
    w = np.asarray(w, dtype=float)
    w = np.clip(w, 0.0, None)
    ssum = w.sum()
    if ssum <= 1e-12:
        raise ValueError("Blend weights sum to ~0 after clipping")
    w = w / ssum
    return arr @ w


def stratified_bootstrap_pr_f1(y, p, t, *, B, rng):
    """Bootstrap PR-AUC and F1 at fixed threshold `t` with **stratified** row resampling.

    Plain i.i.d. row resampling under-represents the minority class composition of
    each pseudo-sample when prevalence is ~1–2%. Here we resample **positives**
    and **negatives** with replacement separately, then concatenate — preserving
    expected class counts per replicate on average.
    """
    y = np.asarray(y).astype(int)
    p = np.asarray(p, dtype=float)
    pos = np.flatnonzero(y == 1)
    neg = np.flatnonzero(y == 0)
    if len(pos) == 0 or len(neg) == 0:
        raise ValueError("stratified_bootstrap_pr_f1 needs both classes present")

    pr_list, f1_list = [], []
    for _ in range(int(B)):
        ip = rng.choice(pos, size=len(pos), replace=True)
        ineg = rng.choice(neg, size=len(neg), replace=True)
        idx = np.concatenate([ip, ineg])
        yi, pi = y[idx], p[idx]
        pr_list.append(average_precision_score(yi, pi))
        y_hat = (pi >= t).astype(int)
        f1_list.append(f1_score(yi, y_hat, zero_division=0))
    return np.asarray(pr_list, dtype=float), np.asarray(f1_list, dtype=float)


def aggregate_blend_tables_across_outers(list_of_dfs, *, variant_col="variant"):
    """Stack per-outer `blend_table` copies (each should include `outer_seed`).

    Returns a wide summary: one row per `variant` with median/p25/p75 for
    `pr_auc_cal` and `pr_auc_test` across outers. Also adds `pr_auc_cal_lcb_iqr`
    as a simple robustness score: median − 0.5×IQR (higher is safer when picking
    blends by calibration stability, **not** for claiming a frequentist CI).
    """
    stacked = pd.concat(list_of_dfs, axis=0, ignore_index=True)
    gcols = [variant_col, "outer_seed"]
    need = {"pr_auc_cal", "pr_auc_test"} <= set(stacked.columns)
    if not need:
        raise ValueError("blend tables must contain pr_auc_cal and pr_auc_test")

    def q25(x):
        return float(np.percentile(x, 25))

    def q75(x):
        return float(np.percentile(x, 75))

    agg = (
        stacked.groupby(variant_col, as_index=False)
        .agg(
            n_outers=("outer_seed", "nunique"),
            pr_auc_cal_median_outer=("pr_auc_cal", "median"),
            pr_auc_cal_p25_outer=("pr_auc_cal", q25),
            pr_auc_cal_p75_outer=("pr_auc_cal", q75),
            pr_auc_test_median_outer=("pr_auc_test", "median"),
            pr_auc_test_p25_outer=("pr_auc_test", q25),
            pr_auc_test_p75_outer=("pr_auc_test", q75),
        )
    )
    iqr = agg["pr_auc_cal_p75_outer"] - agg["pr_auc_cal_p25_outer"]
    agg["pr_auc_cal_lcb_iqr"] = agg["pr_auc_cal_median_outer"] - 0.5 * iqr
    return stacked, agg.sort_values("pr_auc_cal_median_outer", ascending=False)


def posthoc_calibrate_1d(p_cal, y_cal, p_test, *, method="isotonic"):
    """Apply a **second** monotonic / Platt calibration on top of an existing score.

    `method="isotonic"` uses sklearn's IsotonicRegression when both classes have
    enough support; otherwise falls back to logistic regression on `logit(p)`.
    """
    p_cal = np.asarray(p_cal, dtype=float).ravel()
    p_test = np.asarray(p_test, dtype=float).ravel()
    y_cal = np.asarray(y_cal).astype(int)
    n_pos = int((y_cal == 1).sum())
    n_neg = int((y_cal == 0).sum())

    if method == "isotonic" and n_pos >= 3 and n_neg >= 3:
        from sklearn.isotonic import IsotonicRegression

        iso = IsotonicRegression(out_of_bounds="clip")
        iso.fit(p_cal, y_cal)
        return iso.predict(p_cal), iso.predict(p_test), "isotonic"

    # Platt / logistic fallback on clipped logits
    eps = 1e-6
    pc = np.clip(p_cal, eps, 1.0 - eps)
    pt = np.clip(p_test, eps, 1.0 - eps)
    zc = np.log(pc / (1.0 - pc)).reshape(-1, 1)
    zt = np.log(pt / (1.0 - pt)).reshape(-1, 1)
    lr = LogisticRegression(max_iter=4000, solver="lbfgs", class_weight="balanced", random_state=42)
    lr.fit(zc, y_cal)
    return lr.predict_proba(zc)[:, 1], lr.predict_proba(zt)[:, 1], "platt_logit"


def best_recall_at_precision_floor(y, p, prec_floor, grid=None):
    """Max recall on `y` scanning thresholds on scores `p` with precision floor.

    Used only on **calibration** labels for blend selection — not on test.
    """
    if grid is None:
        grid = np.linspace(0.001, 0.999, 399)
    y = np.asarray(y).astype(int)
    p = np.asarray(p, dtype=float)
    best_r, best_t, best_p = -1.0, 0.5, 0.0
    for t in grid:
        y_hat = (p >= t).astype(int)
        prec = precision_score(y, y_hat, zero_division=0)
        if prec < prec_floor:
            continue
        rec = recall_score(y, y_hat, zero_division=0)
        if rec > best_r:
            best_r, best_t, best_p = float(rec), float(t), float(prec)
    return best_r, best_t, best_p


def best_fbeta_at_threshold(y, p, beta, grid=None):
    """Max F_beta over thresholds (calibration-only objective for blends)."""
    if grid is None:
        grid = np.linspace(0.001, 0.999, 399)
    y = np.asarray(y).astype(int)
    p = np.asarray(p, dtype=float)
    best_v, best_t = -1.0, 0.5
    for t in grid:
        y_hat = (p >= t).astype(int)
        v = fbeta_score(y, y_hat, beta=float(beta), zero_division=0)
        if v > best_v:
            best_v, best_t = float(v), float(t)
    return best_v, best_t


def oof_stacked_probability_matrix(
        X_merge,
        y_merge,
        member_names,
        base_builder,
        *,
        n_splits,
        random_state,
):
    """Build out-of-fold positive-class probability columns for each base member.

    `base_builder(name)` must return an **unfitted** sklearn-compatible classifier
    with `fit` / `predict_proba`. Each fold fits on train fold and writes OOF
    predictions on the validation fold only — no leakage into the row's own fit.
    """
    X_merge = np.asarray(X_merge)
    y_merge = np.asarray(y_merge).astype(int)
    n = len(y_merge)
    k = len(member_names)
    oof = np.full((n, k), np.nan, dtype=float)
    skf = StratifiedKFold(n_splits=int(n_splits), shuffle=True, random_state=int(random_state))
    for fold_idx, (tr, va) in enumerate(skf.split(X_merge, y_merge)):
        X_tr, y_tr = X_merge[tr], y_merge[tr]
        X_va = X_merge[va]
        for j, name in enumerate(member_names):
            est = base_builder(name)
            est.fit(X_tr, y_tr)
            oof[va, j] = est.predict_proba(X_va)[:, 1]
    if np.any(np.isnan(oof)):
        raise RuntimeError("OOF matrix still contains NaNs — check folds / builders")
    return oof


def fit_meta_logistic_on_oof(oof, y_merge, *, random_state=42):
    """Train a simple meta logistic regression on OOF stacked columns."""
    meta = LogisticRegression(
        max_iter=12000,
        solver="lbfgs",
        class_weight="balanced",
        random_state=int(random_state),
    )
    meta.fit(np.asarray(oof, dtype=float), np.asarray(y_merge).astype(int))
    return meta


def meta_predict_proba_positive(meta, X_stack):
    """Return positive-class probability from meta logistic."""
    return meta.predict_proba(np.asarray(X_stack, dtype=float))[:, 1]


POLICY_WEIGHT_COLS = [
    ("w_cat", "cat"),
    ("w_xgb", "xgb"),
    ("w_rf", "rf"),
    ("w_rf_b", "rf_b"),
    ("w_xgb_b", "xgb_b"),
    ("w_lgb", "lgb"),
    ("w_lr", "lr"),
]


def row_has_convex_weights(row, weight_cols=POLICY_WEIGHT_COLS):
    for col, _ in weight_cols:
        v = row.get(col, np.nan)
        if v is None or (isinstance(v, float) and np.isnan(v)):
            continue
        if float(v) > 1e-8:
            return True
    return False


def members_weights_from_row(row, weight_cols=POLICY_WEIGHT_COLS):
    pairs = []
    for col, key in weight_cols:
        v = row.get(col, np.nan)
        if v is None or (isinstance(v, float) and np.isnan(v)):
            continue
        v = float(v)
        if v > 1e-8:
            pairs.append((key, v))
    if not pairs:
        raise ValueError("Blend row has no positive simplex weights")
    names = [p[0] for p in pairs]
    w = np.array([p[1] for p in pairs], dtype=float)
    w = np.clip(w, 0.0, None)
    return names, w / w.sum()


def policy_row_a_cal_rank(bt):
    """Policy A: first convex row after current `blend_table` sort (BLEND_RANK_METRIC)."""
    mask = bt.apply(row_has_convex_weights, axis=1)
    if not mask.any():
        raise ValueError("No convex blend rows in blend_table")
    return bt.loc[mask].iloc[0].copy()


def policy_row_b_8way_slsqp(bt):
    # Widest available N-way SLSQP convex blend (member count depends on available bases).
    hit = bt.loc[bt["variant"].astype(str).str.match(r"^\d+way_slsqp_max_pr_cal$")]
    if hit.empty:
        raise ValueError("Nway_slsqp_max_pr_cal not in blend_table")
    return hit.iloc[0].copy()


def policy_row_c_best_test_convex(bt):
    """Policy C: best convex blend by instantaneous test PR-AUC (exploratory / optimistic)."""
    cand = bt.loc[bt.apply(row_has_convex_weights, axis=1)].sort_values(
        "pr_auc_test", ascending=False
    )
    if cand.empty:
        raise ValueError("No convex rows for Policy C")
    return cand.iloc[0].copy()


def evaluate_policy_from_row(
        row,
        P_cal,
        P_test,
        y_cal,
        y_test,
        *,
        policy_label,
        B=800,
        rng=None,
):
    """Cal + test point metrics and stratified bootstrap on test for one blend row."""
    if rng is None:
        rng = np.random.default_rng(42)
    members, w = members_weights_from_row(row)
    p_cal = _blend([P_cal[m] for m in members], w)
    p_test = _blend([P_test[m] for m in members], w)
    t = float(row.get("threshold_f1max_cal", 0.5))
    yhat_cal = (p_cal >= t).astype(int)
    yhat_test = (p_test >= t).astype(int)

    pr_bs_test, f1_bs_test = stratified_bootstrap_pr_f1(y_test, p_test, t, B=int(B), rng=rng)

    n_outer = row.get("n_outers", np.nan)
    return {
        "policy": policy_label,
        "variant": str(row["variant"]),
        "n_members": len(members),
        "n_outers": float(n_outer) if n_outer == n_outer else np.nan,
        "pr_auc_cal": float(average_precision_score(y_cal, p_cal)),
        "pr_auc_test": float(average_precision_score(y_test, p_test)),
        "roc_auc_test": float(roc_auc_score(y_test, p_test)),
        "f1_cal": float(f1_score(y_cal, yhat_cal, zero_division=0)),
        "f1_test": float(f1_score(y_test, yhat_test, zero_division=0)),
        "mcc_test": float(matthews_corrcoef(y_test, yhat_test)),
        "recall_test": float(recall_score(y_test, yhat_test, zero_division=0)),
        "precision_test": float(precision_score(y_test, yhat_test, zero_division=0)),
        "threshold": t,
        "test_PR_AUC_boot_mean": float(pr_bs_test.mean()),
        "test_PR_AUC_boot_p5": float(np.percentile(pr_bs_test, 5)),
        "test_PR_AUC_boot_p95": float(np.percentile(pr_bs_test, 95)),
        "test_F1_boot_mean": float(f1_bs_test.mean()),
    }


def build_policy_comparison_table(P_cal, P_test, y_cal, y_test, blend_table, *, B=800, rng=None):

def build_ensemble_blend_table(P_cal, P_test, y_cal, y_test):
    """One outer split: build §8 blend table."""

    def _safe_p(model, X):
        return np.asarray(model.predict_proba(X)[:, 1], dtype=float)

    all_weight_cols = [
        "w_cat", "w_xgb", "w_rf", "w_rf_b", "w_xgb_b", "w_lgb", "w_lr",
    ]

    def _f1max_t(y, p, grid=np.linspace(0.01, 0.99, 199)):
        best_t, best_f = 0.5, -1.0
        for t in grid:
            f = f1_score(y, (p >= t).astype(int), zero_division=0)
            if f > best_f:
                best_t, best_f = float(t), float(f)
        return best_t

    def _max_f2(y, p, grid=np.linspace(0.01, 0.99, 199)):
        best = -1.0
        for t in grid:
            v = fbeta_score(y, (p >= t).astype(int), beta=2, zero_division=0)
            if v > best:
                best = v
        return float(best)

    def _metrics_at_t(y, p, t):
        yhat = (p >= t).astype(int)
        return {
            "precision": float(precision_score(y, yhat, zero_division=0)),
            "recall": float(recall_score(y, yhat, zero_division=0)),
            "f1_score": float(f1_score(y, yhat, zero_division=0)),
            "accuracy": float(accuracy_score(y, yhat)),
        }

    def _blend(preds, w):
        # Convex combination of probability vectors; clip to avoid -0.0 / negative noise from grid arithmetic.
        arr = np.vstack(preds).T
        w = np.asarray(w, dtype=float)
        w = np.clip(w, 0.0, None)
        s = w.sum()
        if s <= 1e-12:
            raise ValueError("Blend weights sum to ~0 after clipping")
        w = w / s
        return arr @ w

    def _grid_weights(k, step=0.1):
        # Generates simplex grid for k weights with given step (k in {2, 3, 4}).
        vals = np.arange(0, 1 + 1e-12, step)
        out = []
        if k == 2:
            for a in vals:
                b = 1.0 - a
                if b < -1e-9 or b > 1 + 1e-9:
                    continue
                out.append(np.array([float(a), float(b)], dtype=float))
        elif k == 3:
            for a in vals:
                for b in vals:
                    c = 1 - a - b
                    if c < -1e-9:
                        continue
                    c = round(float(c), 10)
                    if c < -1e-9 or c > 1 + 1e-9:
                        continue
                    out.append(np.array([a, b, c], dtype=float))
        elif k == 4:
            for a in vals:
                for b in vals:
                    for c in vals:
                        d = 1 - a - b - c
                        if d < -1e-9:
                            continue
                        d = round(float(d), 10)
                        if d < -1e-9 or d > 1 + 1e-9:
                            continue
                        out.append(np.array([a, b, c, d], dtype=float))
        return out

    def _add_row(rows, variant, members, w):
        p_cal = _blend([P_cal[m] for m in members], w)
        p_test = _blend([P_test[m] for m in members], w)
        t = _f1max_t(y_cal, p_cal)

        row = {
            "variant": variant,
            "notes": "",
            "pr_auc_cal": float(average_precision_score(y_cal, p_cal)),
            "max_f2_cal": _max_f2(y_cal, p_cal),
            "pr_auc_test": float(average_precision_score(y_test, p_test)),
            "roc_auc_test": float(roc_auc_score(y_test, p_test)),
            "threshold_f1max_cal": float(t),
        }
        row.update(_metrics_at_t(y_test, p_test, t))

        for c in all_weight_cols:
            row[c] = np.nan

        mapping = {
            "cat": "w_cat", "xgb": "w_xgb", "rf": "w_rf", "rf_b": "w_rf_b", "xgb_b": "w_xgb_b",
            "lgb": "w_lgb", "lr": "w_lr",
        }
        for m, wi in zip(members, w):
            if m in mapping:
                row[mapping[m]] = float(wi)

        rows.append(row)

    rows = []

    # 3-way baseline: cat/xgb/rf
    m3 = [m for m in ["cat", "xgb", "rf"] if m in P_cal]
    if len(m3) == 3:
        _add_row(rows, "equal_1/3", m3, np.array([1 / 3, 1 / 3, 1 / 3]))

        grid3 = _grid_weights(3, step=0.05)
        best_w3_pr, best_pr = None, -1.0
        best_w3_f2, best_f2 = None, -1.0
        for w in grid3:
            pcal = _blend([P_cal[m] for m in m3], w)
            pr = average_precision_score(y_cal, pcal)
            f2 = _max_f2(y_cal, pcal)
            if pr > best_pr:
                best_pr, best_w3_pr = pr, w
            if f2 > best_f2:
                best_f2, best_w3_f2 = f2, w
        _add_row(rows, "grid_max_pr_auc_cal", m3, best_w3_pr)
        _add_row(rows, "grid_max_f2_cal", m3, best_w3_f2)

    # 4-way pack (cat / xgb / rf / rf_b)
    m4 = [m for m in ["cat", "xgb", "rf", "rf_b"] if m in P_cal]
    if len(m4) == 4:
        _add_row(rows, "four_equal_1/4", m4, np.array([0.25, 0.25, 0.25, 0.25]))
        grid4 = _grid_weights(4, step=0.05)
        best_w4_pr, best4_pr = None, -1.0
        best_w4_f2, best4_f2 = None, -1.0
        best_w4_pr_floor, best4_pr_floor = None, -1.0
        best_w4_f2_floor, best4_f2_floor = None, -1.0
        floor10 = 0.10

        for w in grid4:
            pcal = _blend([P_cal[m] for m in m4], w)
            pr = average_precision_score(y_cal, pcal)
            f2 = _max_f2(y_cal, pcal)
            if pr > best4_pr:
                best4_pr, best_w4_pr = pr, w
            if f2 > best4_f2:

                    best4_pr_floor, best_w4_pr_floor = pr, w
                if f2 > best4_f2_floor:
                    best4_f2_floor, best_w4_f2_floor = f2, w

        _add_row(rows, "four_grid_max_pr_auc_cal", m4, best_w4_pr)
        _add_row(rows, "four_grid_max_f2_cal", m4, best_w4_f2)
        if best_w4_pr_floor is not None:
            _add_row(rows, "four_grid_max_pr_auc_cal_min_w0p10", m4, best_w4_pr_floor)

    def _enumerate_pair_and_triple_blends(rows):
        """All unordered pairs/triples of calibrated members × weight grids (cal-only)."""
        from itertools import combinations

        order = globals().get(
            "BLEND_MEMBER_ORDER",
            ["cat", "xgb", "rf", "rf_b", "xgb_b", "lgb", "lr"],
        )
        members = [m for m in order if m in P_cal]
        n0 = len(rows)
        if len(members) < 2:
            return

        pair_step = float(globals().get("BLEND_PAIR_WEIGHT_STEP", 0.05))
        triple_step = float(globals().get("BLEND_TRIPLE_WEIGHT_STEP", 0.10))
        enum_pairs = bool(globals().get("BLEND_ENUM_ALL_PAIR_GRID", True))
        enum_triples = bool(globals().get("BLEND_ENUM_ALL_TRIPLE_GRID", True))
        pair_presets = globals().get(
            "BLEND_PAIR_PRESETS",
            ((0.5, 0.5), (0.7, 0.3), (0.3, 0.7)),
        )
        add_pair_best = bool(globals().get("BLEND_ADD_PAIR_GRID_MAX_PR_SUMMARY", True))
        add_triple_best = bool(globals().get("BLEND_ADD_TRIPLE_GRID_MAX_PR_SUMMARY", True))

        def _wtag(w):
            return "_".join("{:.2f}".format(float(x)) for x in np.asarray(w, dtype=float))

        for m1, m2 in combinations(members, 2):
            pair = [m1, m2]
            base = "pair_{0}_{1}".format(m1, m2)

            for w1, w2 in pair_presets:
                v = "{0}_preset_w{1}_{2}".format(
                    base, int(round(w1 * 10)), int(round(w2 * 10))
                )
                _add_row(rows, v, pair, np.array([w1, w2], dtype=float))

            grid2 = _grid_weights(2, step=pair_step)
            if enum_pairs:
                for w in grid2:
                    _add_row(rows, "{0}_grid_{1}".format(base, _wtag(w)), pair, w)

            if add_pair_best:
                best_w, best_pr = None, -1.0
                for w in grid2:
                    pr = float(
                        average_precision_score(
                            y_cal, _blend([P_cal[m] for m in pair], w)
                        )
                    )
                    if pr > best_pr:
                        best_pr, best_w = pr, w
                if best_w is not None:
                    _add_row(rows, base + "_grid_max_pr_cal", pair, best_w)

        if len(members) >= 3:
            for m1, m2, m3 in combinations(members, 3):
                triple = [m1, m2, m3]
                base = "triple_{0}_{1}_{2}".format(m1, m2, m3)
                _add_row(rows, base + "_equal", triple, np.array([1 / 3, 1 / 3, 1 / 3]))

                grid3 = _grid_weights(3, step=triple_step)
                if enum_triples:
                    for w in grid3:
                        _add_row(rows, "{0}_grid_{1}".format(base, _wtag(w)), triple, w)

                if add_triple_best:
                    best_w, best_pr = None, -1.0
                    for w in grid3:
                        pr = float(
                            average_precision_score(
                                y_cal, _blend([P_cal[m] for m in triple], w)
                            )
                        )
                        if pr > best_pr:
                            best_pr, best_w = pr, w
                    if best_w is not None:
                        _add_row(rows, base + "_grid_max_pr_cal", triple, best_w)

        print(
            "Enumerated pair/triple blends: +{0} rows ({1} pairs, {2} triples among {3} members)".format(
                len(rows) - n0,
                len(list(combinations(members, 2))),
                len(list(combinations(members, 3))) if len(members) >= 3 else 0,
                len(members),
            )
        )

    _enumerate_pair_and_triple_blends(rows)

    # ---------- 8.1+ Better weight learners: constrained SLSQP + meta stackers (calibration fit only) ----------
    # Note: You cannot legitimately *maximize* `pr_auc_test` with a learned w without using `y_test` (that would
    # be an oracle / contaminated estimate). The methods below either (a) optimize a ranking score on `y_cal`, or
    # (b) fit a meta-classifier on `P_cal` only — same information budget as the old Section 9c meta rows.
    from scipy.optimize import minimize

    def _simplex_feasible_starts(k, rng, *, min_w: float = 0.0, n_random: int = 40, warmstarts=()):
        low = float(min_w)
        if low * k > 1.0 + 1e-9:
            return []
        rem = max(1.0 - k * low, 0.0)

        starts = []
        for w in warmstarts:
            if w is None:
                continue
            w = np.clip(np.asarray(w, dtype=float), low, None)
            s = float(w.sum())
            if s <= 0:
                continue
            w = w / s
            if np.all(w >= low - 1e-12):
                starts.append(w)

        starts.append(np.full(k, 1.0 / k))

        needed = max(0, int(n_random) - len(starts))
        for _ in range(needed):
            if rem <= 0:
                starts.append(np.full(k, low + 1e-12))
                continue
            u = rng.dirichlet(np.ones(k))
            w = low + rem * np.asarray(u, dtype=float)
            starts.append(np.clip(w, low, None))

        out, seen = [], set()
        for w in starts:
            key = tuple(np.round(w, 6))
            if key in seen:
                continue
            seen.add(key)
            out.append(w.astype(np.float64))
        return out

    def _weights_slsqp_maximize(member_names, y_vec, scorer, *,
                                min_w: float = 0.0,
                                n_starts: int = 48,
                                rng_seed: int = 42,
                                warmstarts=()):
        S = np.vstack([P_cal[m] for m in member_names]).astype(np.float64)
        k = S.shape[0]
        yv = np.asarray(y_vec)
        low = float(min_w)
        if k < 2 or low * k > 1.0 + 1e-9:
            raise ValueError("infeasible simplex constraints")

        bnds = tuple((max(low, 1e-12), 1.0) for _ in range(k))
        cons = {"type": "eq", "fun": lambda w, kk=k: float(np.sum(w[:kk]) - 1.0)}

        def negscore(w_raw):
            w = np.asarray(w_raw, dtype=np.float64)
            w = np.clip(w, 1e-12, None)
            w = w / max(w.sum(), 1e-15)
            p = w @ S
            try:
                return float(-scorer(np.asarray(yv), p))
            except Exception:
                return 1e12

        rng = np.random.default_rng(int(rng_seed))
        ws = _simplex_feasible_starts(k, rng, min_w=low, n_random=int(n_starts), warmstarts=warmstarts)

        best_w, best_s = ws[0], float("-inf")
        for w0 in ws:
            res = minimize(
                negscore,
                w0,
                method="SLSQP",
                bounds=bnds,
                constraints=cons,
                options={"maxiter": 2000, "ftol": 1e-11},
            )
            wf = np.clip(np.asarray(res.x, dtype=np.float64), 1e-12, None)
            wf = wf / max(wf.sum(), 1e-15)

            pv = wf @ S
            try:
                sc = float(scorer(np.asarray(yv), pv))
            except Exception:
                sc = float("-inf")
            if sc > best_s:
                best_s = sc
                best_w = wf

        best_w = np.clip(best_w, low, None)
        best_w = best_w / max(best_w.sum(), 1e-15)
        pv = best_w @ S
        best_s = float(scorer(np.asarray(yv), pv))
        return best_w, best_s

    def _add_row_probs(rows, variant, p_cal_vec, p_test_vec):
        t = _f1max_t(y_cal, p_cal_vec)
        row = {
            "variant": variant,
            "notes": "",
            "pr_auc_cal": float(average_precision_score(y_cal, p_cal_vec)),
            "max_f2_cal": _max_f2(y_cal, p_cal_vec),
            "pr_auc_test": float(average_precision_score(y_test, p_test_vec)),
            "roc_auc_test": float(roc_auc_score(y_test, p_test_vec)),
            "threshold_f1max_cal": float(t),
        }
        row.update(_metrics_at_t(y_test, p_test_vec, t))
        for col in all_weight_cols:
            row[col] = np.nan
        rows.append(row)

    def _stack_meta_logreg(rows, members, variant, *, elasticnet_mix: float = 0.0):
        if len(members) < 2:
            return
        Xm = np.column_stack([P_cal[m] for m in members]).astype(np.float64)
        Xt = np.column_stack([P_test[m] for m in members]).astype(np.float64)
        if elasticnet_mix and elasticnet_mix > 0:
            from sklearn.linear_model import SGDClassifier

            meta = SGDClassifier(
                loss="log_loss",
                penalty="elasticnet",
                alpha=3e-3,
                l1_ratio=float(elasticnet_mix),
                max_iter=5000,
                tol=1e-4,
                random_state=42,
                average=True,
                class_weight="balanced",
            )
            meta.fit(Xm, y_cal)

            def _p(clf, X_):
                margins = clf.decision_function(X_)
                return np.clip(
                    1.0 / (1.0 + np.exp(-margins.astype(np.float64))),
                    1e-9,
                    1.0 - 1e-9,
                )

            pc = _p(meta, Xm)
            pt = _p(meta, Xt)
        else:
            lr = LogisticRegression(
                max_iter=12000,
                solver="lbfgs",
                class_weight="balanced",
                random_state=42,
            )
            lr.fit(Xm, y_cal)
            pc = lr.predict_proba(Xm)[:, 1]
            pt = lr.predict_proba(Xt)[:, 1]
        _add_row_probs(rows, variant, pc, pt)

    _pr_scorer = lambda yv, pv: average_precision_score(yv, pv)
    _roc_scorer = lambda yv, pv: roc_auc_score(yv, pv)

    def _bootstrap_idx(y_arr, n_boot=48, rng_seed=43):
        rng = np.random.default_rng(rng_seed)
        y_arr = np.asarray(y_arr).astype(int)
        pos = np.flatnonzero(y_arr == 1)
        neg = np.flatnonzero(y_arr == 0)
        out = []
        for _ in range(int(n_boot)):
            ip = rng.choice(pos, size=max(1, len(pos)), replace=True)
            ineg = rng.choice(neg, size=max(1, len(neg)), replace=True)
            idx = np.concatenate([ip, ineg])
            rng.shuffle(idx)
            out.append(idx)
        return out

    _boot_cal = _bootstrap_idx(y_cal, n_boot=48, rng_seed=43)

    def _robust_boot_roc_scorer(yv, pv):
        vals = []
        for idx in _boot_cal:
            try:
                vals.append(float(roc_auc_score(np.asarray(yv)[idx], pv[idx])))
            except Exception:
                continue
        if not vals:
            return 0.0
        vals = np.asarray(vals, dtype=np.float64)
        return float(np.mean(vals) - 0.35 * np.std(vals))

    # ---------- SLSQP convex blends (replaces Nelder-Mead on softmax, which often plateaus) ----------
    if len(m3) == 3:
        w3, _ = _weights_slsqp_maximize(
            m3, y_cal, _pr_scorer, min_w=0.0,
            warmstarts=[np.array([1 / 3, 1 / 3, 1 / 3]), best_w3_pr],
        )
        print("three_slsqp_max_pr_cal:", np.round(w3, 5).tolist())
        _add_row(rows, "three_slsqp_max_pr_cal", m3, w3)

    if len(m4) == 4:
        w4_pr, score4_pr = _weights_slsqp_maximize(
            m4, y_cal, _pr_scorer, min_w=0.0,
            warmstarts=[np.array([0.25] * 4), best_w4_pr],
        )
        print("four_slsqp_max_pr_cal:", np.round(w4_pr, 5).tolist(), "PR(cal)≈ %.6f" % score4_pr)
        _add_row(rows, "four_slsqp_max_pr_cal", m4, w4_pr)

        w4_pr10, score4_pr10 = _weights_slsqp_maximize(
            m4, y_cal, _pr_scorer, min_w=0.10,
            warmstarts=[best_w4_pr_floor] if best_w4_pr_floor is not None else [np.full(4, 0.25)],
        )
        print("four_slsqp_max_pr_cal_min_w0p10:", np.round(w4_pr10, 5).tolist(), "PR(cal)≈ %.6f" % score4_pr10)
        _add_row(rows, "four_slsqp_max_pr_cal_min_w0p10", m4, w4_pr10)

        w4_ro, _ = _weights_slsqp_maximize(
            m4, y_cal, _roc_scorer, min_w=0.0,
            warmstarts=[w4_pr, np.array([0.25] * 4)],
        )
        print("four_slsqp_max_roc_auc_cal:", np.round(w4_ro, 5).tolist())
        _add_row(rows, "four_slsqp_max_roc_auc_cal", m4, w4_ro)

        w4_rr, _ = _weights_slsqp_maximize(
            m4, y_cal, _robust_boot_roc_scorer, min_w=0.0,
            warmstarts=[w4_ro],
        )
        print("four_slsqp_max_bootrobust_roc_cal:", np.round(w4_rr, 5).tolist())
        _add_row(rows, "four_slsqp_max_bootrobust_roc_cal", m4, w4_rr)

        # --- Operational blend objectives (calibration labels only) ---
        # Maximize **recall** of the blended score subject to a **precision floor**
        # at the best threshold on y_cal (scanned inside best_recall_at_precision_floor).
        def _recall_at_prec_floor_scorer(yv, pv):
            r, _t, _p = best_recall_at_precision_floor(np.asarray(yv), np.asarray(pv), PREC_FLOOR)
            return float(r)

        w4_rp, _ = _weights_slsqp_maximize(
            m4,
            y_cal,
            _recall_at_prec_floor_scorer,
            min_w=0.0,
            warmstarts=[w4_pr, np.full(4, 0.25)],
            n_starts=40,
        )
        _add_row(rows, "four_slsqp_max_recall_at_precfloor_cal", m4, w4_rp)
        rows[-1]["notes"] = (
                '{"objective":"recall_at_precision_floor","prec_floor":'
                + str(float(PREC_FLOOR))
                + "}"
        )

        # Maximize **F_beta** where beta>1 up-weights recall; inner loop scans thresholds
        # on the blended probability (still a cal-only objective for weights).
        def _fbeta_max_threshold_scorer(yv, pv):
            yv = np.asarray(yv).astype(int)
            pv = np.asarray(pv, dtype=float)
            best = 0.0
            for t in np.linspace(0.02, 0.98, 97):
                v = fbeta_score(
                    yv,
                    (pv >= t).astype(int),
                    beta=float(FBETA_OPER),
                    zero_division=0,
                )
                best = max(best, float(v))
            return best

        w4_fb, _ = _weights_slsqp_maximize(
            m4,
            y_cal,
            _fbeta_max_threshold_scorer,
            min_w=0.0,
            warmstarts=[w4_pr10, w4_pr],
            n_starts=40,
        )
        _add_row(rows, "four_slsqp_max_fbeta_oper_scan_cal", m4, w4_fb)
        rows[-1]["notes"] = '{"objective":"max_Fbeta_scan_thresholds","beta":' + str(float(FBETA_OPER)) + "}"

        # --- Post-hoc monotonic / Platt calibration on top of selected convex blends ---
        # Uses helper `posthoc_calibrate_1d` (§3b) — does **not** use y_test.
        for suffix, wvec in (
                ("four_grid_max_pr_auc_cal", best_w4_pr),
                (
                        "four_grid_max_pr_auc_cal_min_w0p10",
                        best_w4_pr_floor if best_w4_pr_floor is not None else best_w4_pr,
                ),
        ):
            if wvec is None:
                continue
            p_cb = _blend([P_cal[m] for m in m4], np.asarray(wvec, dtype=float))
            p_tb = _blend([P_test[m] for m in m4], np.asarray(wvec, dtype=float))
            p_c2, p_t2, meth = posthoc_calibrate_1d(
                p_cb, y_cal, p_tb, method=SECONDARY_CAL_METHOD
            )
            _add_row_probs(
                rows,
                suffix + "_blend_secondary_" + str(meth) + "_cal",
                p_c2,
                p_t2,
            )

    _mw_order = ["cat", "xgb", "rf", "rf_b", "xgb_b", "lgb", "lr"]
    mw = [m for m in _mw_order if m in P_cal]
    if len(mw) >= 3:
        wwide, scrw = _weights_slsqp_maximize(mw, y_cal, _pr_scorer, min_w=0.0, n_starts=72)
        tag = "{0}way_slsqp_max_pr_cal".format(len(mw))
        print(tag + ":", np.round(wwide, 5).tolist(), "PR(cal)≈ %.6f" % scrw)
        _add_row(rows, tag, mw, wwide)

        _stack_meta_logreg(rows, mw, "{0}_meta_lr_balanced_cal".format(len(mw)))
        _stack_meta_logreg(rows, mw, "{0}_meta_sgd_elastic_cal".format(len(mw)), elasticnet_mix=0.65)

    _m4_meta = [m for m in ["cat", "xgb", "rf", "rf_b"] if m in P_cal]
    if len(_m4_meta) == 4:
        _stack_meta_logreg(rows, _m4_meta, "four_pack_meta_lr_balanced_cal")

    blend_df = pd.DataFrame(rows)
    cols = [
        "variant", "notes",
        "w_cat", "w_xgb", "w_rf", "w_rf_b", "w_xgb_b", "w_lgb", "w_lr",
        "pr_auc_cal", "max_f2_cal", "pr_auc_test", "roc_auc_test",
        "precision", "recall", "f1_score", "accuracy", "threshold_f1max_cal",
    ]
    blend_df = blend_df[[c for c in cols if c in blend_df.columns]]
    return blend_df

## 4. Wrapper and imbalance weighting (`scale_pos_weight`)

Why wrapper beyond CatBoost:
- some sklearn workflows (cloning, uniform helper interfaces) are smoother with a thin wrapper,
- this notebook standardizes `.predict_proba` handling and metadata.

What `scale_pos_weight` is:
- a class-imbalance multiplier (roughly `n_negative / n_positive`) used by some boosters,
- it increases loss pressure on positives,
- useful for rare positives, but can hurt calibration if overused.


########## CELL 12 [code] ##########
class CatBoostClassifierWrapper(ClassifierMixin, BaseEstimator):
    def __init__(self, **kwargs):
        self.kwargs = kwargs
        self.model_ = CatBoostClassifier(**kwargs)

    def get_params(self, deep=True):
        return dict(self.kwargs)

    def set_params(self, **params):
        self.kwargs.update(params)
        self.model_ = CatBoostClassifier(**self.kwargs)
        return self

    def fit(self, X, y, **fit_params):
        self.model_.fit(X, y, **fit_params)
        self.classes_ = np.unique(y)
        self.n_features_in_ = X.shape[1]
        return self

    def predict(self, X):
        return self.model_.predict(X)

    def predict_proba(self, X):
        return self.model_.predict_proba(X)


def pos_weight(y):
    n_pos = int((y == 1).sum())
    n_neg = int((y == 0).sum())
    return float(n_neg / max(n_pos, 1))

## 5. Individual model training and metric rationale

Is scoring by average precision rational here?
- Yes. In heavy imbalance, PR-AUC is usually more informative than ROC-AUC for positive retrieval.
- ROC-AUC can look high even when precision is weak.

Complementary metrics:
- constrained recall (`max recall @ precision >= p_min`),
- F-beta,
- cost-sensitive utility,
- MCC for thresholded quality.

def tune_booster_early_stop(factory_fn, param_grid, X_fit, y_fit, X_es, y_es):
    best = None
    best_ap = -1.0
    best_params = None
    for params in param_grid:
        model = factory_fn(**params)
        p_es = model.predict_proba(X_es)[:, 1]
        ap = average_precision_score(y_es, p_es)
        if ap > best_ap:
            best_ap = ap
            best = model
            best_params = params
    return best, best_params, float(best_ap)

## 5b. CatBoost diagnostic & reconfig (post-fix follow-up)

After the §5 bug fixes (real early stopping + propagated `best_iteration` at refit), CatBoost moved from being the **leading tree** in the old buggy run to the **weakest tree** here (calibrated test PR-AUC ≈ 0.49 vs XGB / LGB / RF_b at 0.55–0.61). That is unexpected — Cat is normally competitive on tabular features — so we want to rule out two plausible explanations before accepting the new ranking as the truth:

1. **`early_stopping_rounds=70` is firing too eagerly.**
   With `auto_class_weights="Balanced"`, a 44-positive `X_fit`, and an 11-positive `X_es`, the eval `Logloss` curve can plateau briefly even when the underlying ranker (PR-AUC) is still improving. A 70-round patience window may cut Cat off after only a handful of trees and leave it underfit. The other boosters (XGB / LGB) have shallower learning rates and benefit from the same patience differently.

2. **`auto_class_weights="Balanced"` distorts probability geometry.**
   Cat's balanced mode multiplies positive-row gradients by roughly the negative-to-positive ratio (~55× on this set). With only 44 positives in `X_fit`, this magnifies a few noisy rows; the resulting score distribution is hard for a 5-fold sigmoid calibrator (run on 10 cal positives) to fix. Removing the in-loss reweighting and relying on the §7 Platt calibration instead often gives a cleaner probability surface — the same pattern that makes "vanilla XGB + calibration" beat "XGB + `scale_pos_weight` + calibration" in many imbalanced setups.

### What this section does

The next code cell:

1. **Diagnoses** the current §5 winner — prints `best_cat.model_.get_best_iteration()` plus its iteration cap, early-stop window, and `auto_class_weights` setting so you can see how Cat actually trained.
2. **Reconfigures** Cat over a small grid that varies both the suspected confounders at once (`iterations=3000`, `early_stopping_rounds=200`, `auto_class_weights ∈ {None, "Balanced"}`) and scores each candidate by AP on `X_es` — the same signal §5 already uses, so no extra calibration / test data leaks in.
3. **Replaces** `best_cat` (and updates `cat_params` / `cat_ap`) **only if** a reconfig candidate strictly beats the original §5 winner on that `X_es` AP. The replacement is downstream-safe: §7's `_refit_merge_bases_for_outer` already calls `clone(best_cat).set_params(iterations=_best_iter(best_cat, "cat", ...)+1).fit(X_merge_o, ...)`, so the new `auto_class_weights` / ES settings flow through automatically via the wrapper's `kwargs`.

### How to read the output

- If the diagnostic shows Cat stopping at e.g. iteration 30 / 2000, hypothesis (1) is plausible — a longer ES window should help.
- If the reconfig winner has `auto_class_weights=None`, hypothesis (2) is the dominant explanation. Cat's calibrated test PR-AUC in §7 should jump after the replacement.
- If neither reconfig beats the original AP, both hypotheses are rejected and the new ranking ("Cat is genuinely weakest on this feature set") is the honest answer — likely the 173 → 88 feature pruning trimmed columns Cat was relying on.

Either way, the replacement is **gated on `X_es` AP only**, so the §10 deployment metric stays an honest test-set readout regardless of what this cell decides.

class _PrefitClassifierBridge(ClassifierMixin, BaseEstimator):
    """Prefit wrapper for CalibratedClassifierCV.

    Some prefit estimators can be mis-labeled by sklearn's is_classifier(), which breaks
    predict_proba inside calibration. Inheriting ClassifierMixin keeps explicit classifier tags.
    """

    def __init__(self, fitted_clf):
        self.fitted_clf = fitted_clf

    def fit(self, X, y):
        return self

    def predict(self, X):
        return self.fitted_clf.predict(X)

    def predict_proba(self, X):
        return self.fitted_clf.predict_proba(X)

    @property
    def classes_(self):
        return self.fitted_clf.classes_

    def __sklearn_clone__(self):
        return self

    def __sklearn_is_fitted__(self):
        return True


def calibrate_prefit(base_fitted, Xc, yc, method="sigmoid"):
    """Sigmoid (Platt) calibration on held-out folds inside `X_cal` only."""
    n_pos = int((yc == 1).sum())
    n_neg = int((yc == 0).sum())
    k = min(5, n_pos, n_neg)
    if k < 2:
        raise ValueError(f"Need >=2 samples per class for calibration, got pos={n_pos}, neg={n_neg}")
    if not hasattr(base_fitted, "classes_"):
        base_fitted.classes_ = np.array([0, 1])
    if not hasattr(base_fitted, "n_features_in_"):
        base_fitted.n_features_in_ = np.asarray(Xc).shape[1]
    cal = CalibratedClassifierCV(estimator=_PrefitClassifierBridge(base_fitted), method=method, cv=k)
    cal.fit(Xc, yc)
    return cal


def _best_iter(model, attr, default):
    """Safe extractor for {XGB.best_iteration, LGB.best_iteration_, Cat get_best_iteration()}.

    Falls back to `default` when early-stop never fired (e.g. ran to the cap).
    """
    if attr == "cat":
        try:
            v = model.model_.get_best_iteration()
        except Exception:
            v = None
    else:
        v = getattr(model, attr, None)
    if v is None or (isinstance(v, float) and not np.isfinite(v)):
        return int(default)
    return int(v)


def _refit_merge_bases_for_outer(X_merge_o, y_merge_o, outer_seed):
    """Return dict of **uncalibrated** fitted bases for one outer `X_merge_o`.

    Hyperparameters are frozen from §5 tuning; only the training rows change with `outer_seed`.
    For boosters we also freeze the `best_iteration` discovered in §5 so the refit doesn't
    blow through the entire iterations cap (2000 rounds) without early stop.
    """
    # LR: clone + refit so X_cal_o is never inside its training set (previously
    # `bases["lr"] = best_lr`, which was fit on X_merge and overlapped X_cal_o).
    best_lr_m = clone(best_lr)
    best_lr_m.fit(X_merge_o, y_merge_o)

    best_rf_m = clone(best_rf)
    best_rf_m.fit(X_merge_o, y_merge_o)

    cat_iter = _best_iter(best_cat, "cat", best_cat.kwargs.get("iterations", 1200)) + 1
    best_cat_m = clone(best_cat)
    best_cat_m.set_params(iterations=cat_iter)
    best_cat_m.fit(X_merge_o, y_merge_o)

    xgb_n = _best_iter(best_xgb, "best_iteration", best_xgb.n_estimators) + 1
    best_xgb_m = clone(best_xgb)
    best_xgb_m.set_params(callbacks=None, early_stopping_rounds=None, n_estimators=xgb_n)
    best_xgb_m.fit(X_merge_o, y_merge_o)

    lgb_n = _best_iter(best_lgb, "best_iteration_", best_lgb.n_estimators) + 1
    best_lgb_m = clone(best_lgb)
    best_lgb_m.set_params(n_estimators=lgb_n)
    best_lgb_m.fit(X_merge_o, y_merge_o)

    # Diversity heads: same architecture, different stochastic path / subsampling — reduces
    # error correlation between parallel gradient boosted trees when later linearly blended.
    best_rf_mb = clone(best_rf)
    best_rf_mb.set_params(random_state=137 + int(outer_seed), max_samples=0.88)

## 8. Ensemble blends (tables emitted from **§7**)

The **numeric** blend grid, SLSQP rows, meta rows, **outer-seed aggregates**, **OOF meta**, **operational** objectives, **post-hoc** blend calibration, and **diversity** heads are all computed in **§7** after calibration so they see the correct `P_cal` / `P_test` for each outer split. The next code cell only prints a short echo for logs.

This section still documents what those rows mean:
- **All unordered pairs** of calibrated members: named presets (0.5/0.5, 0.7/0.3, …), full **(w, 1−w)** grid at `BLEND_PAIR_WEIGHT_STEP`, plus `pair_{a}_{b}_grid_max_pr_cal`.
- **All unordered triples**: equal weights, full simplex grid at `BLEND_TRIPLE_WEIGHT_STEP`, plus `triple_{a}_{b}_{c}_grid_max_pr_cal`.
- Legacy 3-way/4-way cat/xgb/rf/rf_b **grids** + **SLSQP** on `w` (optionally `w_i ≥ 0.10`),
- **Wide** blends including `lgb`, `lr`, `rf_b`, `xgb_b`,
- **In-sample meta** on `P_cal` vs **OOF meta** on uncalibrated `X_merge` features (see `meta_oob_*` variants),
- **Outer repeats**: `blend_table` gains `*_median_outer` / `*_p25_outer` / `*_p75_outer` columns; default **sort** uses `BLEND_RANK_METRIC` from §3 (prefers calibration stability across outers unless you opt into median test PR-AUC).

Weight columns: `w_cat`, `w_xgb`, `w_rf`, `w_rf_b`, `w_xgb_b`, `w_lgb`, `w_lr`, plus optional `notes` JSON for operational rows.

**Continuous weight search:** `scipy.optimize.minimize` **SLSQP** on the simplex. **`pr_auc_test`** is **reporting only**; `y_test` is not used to pick weights in shipped modes (oracle note below still applies if you change `BLEND_RANK_METRIC` to a test-based key across many variants).

### Cal vs test PR-AUC gap — leakage or overfitting?

A **drop** from `pr_auc_cal` to `pr_auc_test` is **expected** when weights are chosen **using calibration scores** (same data used to *select* the blend is not a second fresh holdout). That is **selection pressure / overfitting to the calibration set**, not necessarily **train–test leakage**.

**Leakage** would more often show up as: duplicate rows across splits, absurd single-feature AUC, or **fit** scores far above **test** with no benign explanation. **Section 11** quantifies train/cal/test gaps per model; use it together with section 2 probes — not the blend cal–test gap alone.

### Learning blend weights

Calibration is used for **selection**:

- **Discrete grid:** exhaustive nonnegative weights summing to 1 (`grid_max_*` rows).
- **SLSQP / simplex:** `three_slsqp_max_pr_cal`, `four_slsqp_max_pr_cal`, **`four_slsqp_max_pr_cal_min_w0p10`** (like your old **`four_grid_max_pr_min_w10pct`**, discourages collapsing one model to zero on cal), **`N`-way blends** adding `lgb` + `lr`.
- **Meta stackers (in-sample):** `LogisticRegression` / elastic-net `SGDClassifier` on **`P_cal`** (compare to **`meta_oob_*`** trained on **OOF** merge features in §7).
- **Operational rows:** recall at **precision floor** (`PREC_FLOOR`) and **\(F_\beta\)** scan on calibration only (`notes` JSON).

This is **not** full nested CV for every base learner; outer loops **reuse §5 tuned hyperparameters** and refit weights/calibration per seed. In-sample meta is not OOF; use **`meta_oob_*`** when you want the cleaner meta protocol. Maximizing **`pr_auc_test` with many variants still risks test-selection pressure** if you set `BLEND_RANK_METRIC` accordingly—the default avoids that.

**Test metrics** still estimate generalization if `X_test` is exchangeable enough with train—combine **bootstrap** uncertainty (section **10**) with **gap** diagnostics (section **11**).

### “Rank blends by the metric you operate on”

**PR-AUC** summarizes ranking over **all** thresholds. In production you usually fix **one** threshold (cost-sensitive, precision floor, regulatory cap on false positives, etc.). If your operating policy is “maximize recall subject to precision ≥ 0.35”, then **after** producing calibrated scores you should **rank candidate blends by that constrained recall on `y_cal`**, not only by PR-AUC. Section 9 already searches thresholds per model; section **10** reports **pointwise** metrics at the blend’s deployed threshold from this table.

## 8c. Cross-validation on train (Phase 4)

**70/30** train/test comes from `../modeling/preprocessing/preprocessing.ipynb` (`TEST_SIZE=0.30`). This block runs **5-fold stratified CV on `X_train` only** (never touches frozen `X_test`).

Per fold we refit **cat / xgb / rf / lgb / lr** with §5 hyperparameters, calibrate on the fold's calibration slice, then report validation PR-AUC for four policies:

- **A_cv_Nway_slsqp**: SLSQP simplex over all 5 calibrated bases per fold (CV mirror of §7's 7-way SLSQP family). _v3: now includes LR; was 4-way in v2._
- **B_cv_lgb_single**: **LGB only** — simplest deployable single model baseline.
- **C_cv_equal4_blend**: unweighted mean of cat+xgb+rf+lgb on fold cal — simple blend baseline.
- **D_cv_xgb_lr_pair_slsqp** _(v3, new)_: 2-member SLSQP on `{xgb, lr}` per fold — the direct CV analog of §10's deployed `pair_xgb_lr_grid_*` blend.

Outputs: **mean ± std PR-AUC** across folds. Treat `D_cv_xgb_lr_pair_slsqp` as the honest CV estimate for the currently-deployed Policy A.

from scipy.optimize import minimize
from sklearn.base import clone

N_CV_FOLDS = 5
CV_SEED = 42

# v3: LR is now a first-class CV member so the per-fold SLSQP search is
# directly comparable to §7's 7-way SLSQP family, and Policy D (an `xgb+lr`
# pair) can be added below as the direct CV analog of §10's deployed
# `pair_xgb_lr_grid_*` blend.
CV_MEMBERS = ["cat", "xgb", "rf", "lgb", "lr"]


def _slsqp_max_pr_on_cal(member_names, P_cal_dict, y_cal_v, *, n_starts=24, seed=0):
    S = np.vstack([P_cal_dict[m] for m in member_names]).astype(np.float64)
    k = S.shape[0]
    yv = np.asarray(y_cal_v).astype(int)
    bnds = tuple((1e-12, 1.0) for _ in range(k))
    cons = {"type": "eq", "fun": lambda w, kk=k: float(np.sum(w[:kk]) - 1.0)}
    rng = np.random.default_rng(int(seed))

    def neg_ap(w_raw):
        w = np.clip(np.asarray(w_raw, dtype=float), 1e-12, None)
        w = w / w.sum()
        return -float(average_precision_score(yv, w @ S))

    starts = [np.full(k, 1.0 / k)]
    for _ in range(int(n_starts)):
        starts.append(rng.dirichlet(np.ones(k)))
    best_w, best_ap = starts[0], -1.0
    for w0 in starts:
        res = minimize(neg_ap, w0, method="SLSQP", bounds=bnds, constraints=cons, options={"maxiter": 800})
        wf = np.clip(res.x, 1e-12, None)
        wf = wf / wf.sum()
        ap = float(average_precision_score(yv, wf @ S))
        if ap > best_ap:
            best_ap, best_w = ap, wf
    return best_w, best_ap


def _fit_fold_models_and_probs(X_fit, y_fit, X_es, y_es, X_cal, y_cal, X_va, *, fold_idx=0):
    """Refit merge bases (fixed §5 params), calibrate, return P_cal and P_va dicts."""
    X_merge = np.vstack([X_fit, X_es])
    y_merge = np.concatenate([y_fit, y_es])

    cat_iter = _best_iter(best_cat, "cat", best_cat.kwargs.get("iterations", 1200)) + 1
    cat_m = clone(best_cat)
    cat_m.set_params(iterations=cat_iter)
    cat_m.fit(X_merge, y_merge)

    xgb_n = _best_iter(best_xgb, "best_iteration", best_xgb.n_estimators) + 1
    xgb_m = clone(best_xgb)
    xgb_m.set_params(callbacks=None, early_stopping_rounds=None, n_estimators=xgb_n)
    xgb_m.fit(X_merge, y_merge)

    rf_m = clone(best_rf)
    rf_m.set_params(random_state=137 + fold_idx, max_samples=0.88)
    rf_m.fit(X_merge, y_merge)

    lgb_n = _best_iter(best_lgb, "best_iteration_", best_lgb.n_estimators) + 1
    lgb_m = clone(best_lgb)
    lgb_m.set_params(n_estimators=lgb_n, random_state=91 + fold_idx)
    lgb_m.fit(X_merge, y_merge)

    # v3: refit LR on the fold's X_merge so Phase 4 spans the same member
    # family as §7 (cat + xgb + rf + lgb + lr). LR has no early-stop hyperparam,
    # so a plain clone + refit is sufficient.
    lr_m = clone(best_lr)
    lr_m.fit(X_merge, y_merge)

    bases = {"cat": cat_m, "xgb": xgb_m, "rf": rf_m, "lgb": lgb_m, "lr": lr_m}

def best_f1_threshold(y, p, grid=None):
    if grid is None:
        grid = np.linspace(0.01, 0.99, 199)
    best_t, best_v = 0.5, -1.0
    for t in grid:
        v = f1_score(y, (p >= t).astype(int), zero_division=0)
        if v > best_v:
            best_t, best_v = float(t), float(v)
    return best_t, best_v


def best_fbeta_threshold(y, p, beta=2.0, grid=None):
    if grid is None: grid = np.linspace(0.01, 0.99, 199)
    best_t, best_v = 0.5, -1.0
    for t in grid:
        v = fbeta_score(y, (p >= t).astype(int), beta=beta, zero_division=0)
        if v > best_v:
            best_t, best_v = float(t), float(v)
    return best_t, best_v


def best_recall_at_precision_floor(y, p, p_floor=0.35, grid=None):
    if grid is None: grid = np.linspace(0.01, 0.99, 199)
    best = (0.5, 0.0, 0.0)
    for t in grid:
        yhat = (p >= t).astype(int)
        prec = precision_score(y, yhat, zero_division=0)
        rec = recall_score(y, yhat, zero_division=0)
        if prec >= p_floor and rec > best[1]:
            best = (float(t), float(rec), float(prec))
    return best

def _pick_t_on_cal(y, p, *, policy=BASE_THRESHOLD_POLICY, grid=None):
    """Pick a deployment threshold on calibration only (never on test)."""
    if grid is None:
        grid = np.linspace(0.01, 0.99, 199)
    if policy == "f1":
        t, _ = best_f1_threshold(y, p, grid=grid)
    elif policy == "f2":

    elif policy == "recall_at_prec35":

    else:
        raise ValueError(policy)
    return float(t)


def _full_point_metrics_at_t(y_true, p, t, split):
    """All point + ranking metrics at threshold `t`, plus CM cells and Brier."""
    yhat = (p >= t).astype(int)
    tn, fp, fn, tp = confusion_matrix(y_true, yhat, labels=[0, 1]).ravel()
    spec = float(tn / (tn + fp)) if (tn + fp) > 0 else np.nan
    npv = float(tn / (tn + fn)) if (tn + fn) > 0 else np.nan
    return {
        "split": split,
        "threshold": float(t),
        "n": int(len(y_true)),
        "n_pos": int((y_true == 1).sum()),
        "TP": int(tp),
        "FP": int(fp),
        "TN": int(tn),
        "FN": int(fn),
        "accuracy": float(accuracy_score(y_true, yhat)),
        "precision_ppv": float(precision_score(y_true, yhat, zero_division=0)),
        "recall_sensitivity": float(recall_score(y_true, yhat, zero_division=0)),
        "specificity": spec,
        "NPV": npv,
        "f1": float(f1_score(y_true, yhat, zero_division=0)),
        "f2": float(fbeta_score(y_true, yhat, beta=2.0, zero_division=0)),
        "f0_5": float(fbeta_score(y_true, yhat, beta=0.5, zero_division=0)),
        "MCC": float(matthews_corrcoef(y_true, yhat)),
        "balanced_accuracy": float(balanced_accuracy_score(y_true, yhat)),
        "pr_auc": float(average_precision_score(y_true, p)),
        "roc_auc": float(roc_auc_score(y_true, p)),
        "brier": float(brier_score_loss(y_true, p)),
    }

## 10. Operational metrics and stability (deployment-oriented)

### Why this section exists (philosophy)

**Ranking metrics** (ROC-AUC, PR-AUC) integrate performance over **many** thresholds. They are excellent for **model comparison during development**, but a deployed system commits to **one** threshold and cares about **confusion counts**, **error costs**, and **stability** when data are scarce.

This section therefore:

1. Takes the **first convex blend row** in `blend_table` **after the §7 sort** (`BLEND_RANK_METRIC`, defaulting to calibration stability across outers). Meta / OOF rows may rank higher but have **NaN** simplex weights — they are skipped for the fixed-threshold path until you add explicit meta probability plumbing here.
2. Rebuilds its calibrated probability vector on **calibration** and **test**.
3. Applies the **same** threshold already stored in that row (`threshold_f1max_cal`, i.e. F1-optimal on `y_cal` for that blend).
4. Reports **pointwise** metrics: confusion matrix cells, PPV, NPV, sensitivity, specificity, MCC, balanced accuracy — on cal and test.
5. **Stratified bootstrap** (§3b helper): resample positives and negatives **separately** with replacement, then concatenate — more appropriate than i.i.d. row bootstrap when prevalence is ~1–2%. Summaries report mean and p5/p95 for PR-AUC and F1 at the fixed deployment threshold.

Figures make the bootstrap distributions visible at a glance.

4. **Confusion matrices** for the **top blend** (calibration vs test at `T_deploy`) and for up to **six individual models** ranked by `f1_test_at_t_f1` in section 9 (each at its own F1-optimal threshold on calibration).

# 10b. Comprehensive winner-blend metrics (multiple candidate winners)
#
# Reports a set of "winner" blend variants pulled from `blend_table`:
#   - Policy A: first convex row after §7 sort (calibration-rank, default §10 pick)
#   - Policy B: widest Nway SLSQP convex blend on cal PR-AUC
#   - Policy C: best convex blend by test PR-AUC (exploratory ceiling only)
#   - top-K convex blends by median cal PR-AUC across outer seeds
#   - OOF-meta logistic (raw + secondary isotonic / Platt) when present
#
# For each candidate we recover convex weights (or rebuild meta predictions),
# pick a threshold by F1-max on calibration (same policy as §10), and compute
# the same point metrics + ranking metrics as §9b on calibration and test:
# accuracy, precision (PPV), recall (sensitivity), specificity, NPV, F1, F2,
# F0.5, MCC, balanced accuracy, Brier, PR-AUC, ROC-AUC. A 90% stratified
# bootstrap interval on test (B=500, resampling positives / negatives
# separately) follows the same uncertainty discipline as §10.
# Confusion matrices at the deploy threshold are plotted in a grid.
# =============================================================================
import matplotlib.pyplot as plt
from sklearn.metrics import ConfusionMatrixDisplay
from IPython.display import Markdown, display

TOPK_WINNERS = 5
WINNER_THRESHOLD_POLICY = "f1"  # "f1" | "f2" | "recall_at_prec35"


def _build_winner_candidates(bt):
    convex_mask = bt.apply(row_has_convex_weights, axis=1)
    convex = bt.loc[convex_mask].copy()

    seen, ordered = set(), []

    def _push(label, row):
        key = str(row["variant"])
        if key in seen:
            return
        seen.add(key)
        ordered.append((label, row))

    try:
        _push("policy_A_cal_rank_convex", policy_row_a_cal_rank(bt))
    except Exception as exc:
        print("[policy A skipped]", exc)
    try:
        _push("policy_B_Nway_slsqp_max_pr_cal", policy_row_b_8way_slsqp(bt))
    except Exception as exc:
        print("[policy B skipped]", exc)
    try:
        _push("policy_C_test_best_convex_EXPLORATORY", policy_row_c_best_test_convex(bt))
    except Exception as exc:
        print("[policy C skipped]", exc)

    sort_col = (
        "pr_auc_cal_median_outer"
        if "pr_auc_cal_median_outer" in convex.columns
        else "pr_auc_cal"
    )
    convex_sorted = convex.sort_values(sort_col, ascending=False)
    for _, row in convex_sorted.head(int(TOPK_WINNERS)).iterrows():
        _push("topK_cal_median::" + str(row["variant"]), row)

    for vname in (
            "meta_oob_lr_raw_on_uncal_stack_cal",
            "meta_oob_lr_secondary_isotonic_cal",
            "meta_oob_lr_secondary_platt_logit_cal",
    ):
        m = bt.loc[bt["variant"].astype(str) == vname]
        if not m.empty:
            _push("meta::" + vname, m.iloc[0])
    return ordered


def _scores_from_row(row):
    """Rebuild (p_cal, p_test, members, weights) from a blend_table row.

    - Convex rows: blend P_cal / P_test members by stored simplex weights.
    - meta_oob rows: refit OOF members on full X_merge and apply meta logistic
      (plus secondary isotonic / Platt when the variant name says so).
    """
    if row_has_convex_weights(row):
        members, w = members_weights_from_row(row)
        p_c = _blend([P_cal[m] for m in members], w)
        p_t = _blend([P_test[m] for m in members], w)
        return p_c, p_t, members, w

    if str(row["variant"]).startswith("meta_oob_lr"):
        if isinstance(meta_oob_payload, dict) and meta_oob_payload.get("skipped"):
            raise RuntimeError("meta_oob skipped at fit time; cannot rebuild")
        members_meta = meta_oob_payload["members"]
        full_cal, full_te = [], []
        for nm in members_meta:
            mfull = _oob_builder(nm)
            mfull.fit(X_merge, y_merge)
            full_cal.append(mfull.predict_proba(X_cal)[:, 1])
            full_te.append(mfull.predict_proba(X_test)[:, 1])
        Xc = np.column_stack(full_cal).astype(np.float64)
        Xt = np.column_stack(full_te).astype(np.float64)
        p_c = meta_predict_proba_positive(meta_oob, Xc)
        p_t = meta_predict_proba_positive(meta_oob, Xt)
        if "secondary" in str(row["variant"]):
            method = meta_oob_payload.get("secondary", "isotonic")
            p_c, p_t, _ = posthoc_calibrate_1d(p_c, y_cal, p_t, method=method)
        return p_c, p_t, members_meta, None

    raise ValueError("Cannot rebuild scores for variant: " + str(row["variant"]))

## 11. ROC-AUC suspicion: overfitting or leakage diagnostics

High ROC-AUC **alone** is not proof of leakage: with strong separation on negatives, ROC can be very high while **PR-AUC stays modest** (rare positives in the score tails).

This table compares **fit / cal / test** for each **calibrated** model:

- **`roc_gap_fit_test` / `pr_gap_fit_test`**: large gaps can mean **overfitting** (fit easier than test) or **shift** — not automatically leakage.
- **`brier_gap_test_minus_cal`**: probability calibration drift between cal and test.

**Together with section 2** (duplicate rows, single-feature AUC scan): if those are clean and gaps look like “hard class + small test positives”, leakage is **less** likely than **variance / domain shift**.

The bar chart emphasizes **PR** on fit vs test per model (calibration in between) for a quick visual.
